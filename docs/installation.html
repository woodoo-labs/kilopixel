Installation

Kilopixel is a single JavaScript file. Include it with a <script> tag in any HTML file: there are no dependencies, no build tools, and no local web server to set up.

1. Download & Include

Download the minified engine file (pxl.min.js, ~66KB, ~20KB gzipped) or the complete boilerplate starter kit using the buttons below and save it to your computer.

Include the script in the <head> of your HTML document. The browser then knows Kilopixel's elements before it reaches them in the page, so each stage takes its size as soon as it is parsed and the content below it doesn't jump while the page loads.

<!-- Include Kilopixel in the head of your document -->
<script src="pxl.min.js"></script>

2. Stage Size

A stage is as wide as its parent element, and its height follows its ratio attribute (16 / 9 unless set). It needs no CSS of its own.

Some parents take their width from their content: a wrapper centered in a flex or grid container, an inline-block element, or an absolutely positioned card. A stage gives such a parent no width, so there it is 300 CSS pixels wide, the same default as a <canvas>. Give the parent or the stage a width to change that:

<style>
  .page { display: flex; justify-content: center; }
  /* The card takes its width from its content: give it one */
  .card { width: min(100%, 800px); }
</style>

<div class="page">
  <div class="card">
    <pxl-stage ratio="16 / 9">…</pxl-stage>
  </div>
</div>

Your CSS Wins

Kilopixel's default styles for <pxl-stage> (display, position, width) have the lowest priority, so any rule in your stylesheet overrides them without !important, for example pxl-stage { width: 600px; }. In JavaScript, set single style properties (stage.style.border = …) instead of replacing the whole style attribute: it holds the stage's aspect ratio.

3. Fullscreen Starter Boilerplate

A complete starter page to copy. A short CSS rule in the <head> removes the browser's page margin, sets a dark background and hides the scrollbars, so the stage spans the full width of the window.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Kilopixel Starter</title>
  <style>
    body {
      margin: 0;
      background: #0f172a;
      overflow: hidden;
    }
  </style>
  <script src="js/pxl.min.js"></script>
</head>
<body>

  <!-- Responsive stage that fills the entire viewport -->
  <pxl-stage ratio="16 / 9">
    <pxl-layer>
      <pxl-grid stroke="#1e293b" major="4"></pxl-grid>
      <!-- Circle, pulses with wave() -->
      <pxl-circle x="500" y="300" r="80 + wave(2) * 20" fill="#f97316"></pxl-circle>
    </pxl-layer>
  </pxl-stage>
</body>
</html>

4. No Web Server Needed

Opening a Local File

Kilopixel loads no other files, so a page also works when it is opened as a local file (file://). Save index.html anywhere on your computer and open it with a double-click: no Node.js, bundler or local web server is needed.
