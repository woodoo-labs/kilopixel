Installation & Setup

Getting started with Kilopixel takes less than a minute. With zero dependencies, zero build tools, and zero local web server requirements, you can build declarative, high-performance HTML5 Canvas graphics in any standard HTML file.

1. Download & Include

Download the minified engine file (pxl.min.js, ~44KB) or the complete boilerplate starter kit using the buttons below and save it to your computer.

Include the script at the bottom of your HTML document's <body> tag (right before the closing </body>). Placing it at the bottom ensures that all declarative HTML5 elements are already parsed in the DOM when the script initializes and registers Kilopixel's custom HTML elements.

<!-- Include Kilopixel at the bottom of your document body -->
<script src="pxl.min.js"></script>

2. Fullscreen Starter Boilerplate

Here is a complete, copy-pasteable starter template. It uses a tiny 4-line CSS reset in the <head> to remove browser margins and enable a sleek, fullscreen responsive canvas â€” without requiring external stylesheets or inline style attributes.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Kilopixel Starter</title>
  <style>
    body {
      margin: 0;
      background: #0f172a;
      overflow: hidden;
    }
  </style>
</head>
<body>

  <!-- Responsive stage that fills the entire viewport -->
  <pxl-stage ratio="16 / 9">
    <pxl-layer>
      <pxl-grid stroke="#1e293b" major="4"></pxl-grid>
      <pxl-circle 
        x="500" 
        y="300" 
        r="80 + wave(2) * 20" 
        fill="#f97316">
      </pxl-circle>
    </pxl-layer>
  </pxl-stage>

  <script src="js/pxl.min.js"></script>
</body>
</html>

3. Zero Web Server Required (Works 100% Offline)

Double-Click and Run Anywhere

Unlike most modern JavaScript frameworks or 3D libraries that require Node.js, bundlers, or a local web server just to display a page, Kilopixel has zero CORS or file-system restrictions. You can save index.html anywhere on your computer and double-click it to open directly in any browser via the file:// protocol at a full 60fps.
