Installation & Setup

Getting started with Kilopixel takes less than a minute. With zero dependencies, zero build tools, and zero local web server requirements, you can build declarative, high-performance HTML5 Canvas graphics in any standard HTML file.

1. Download & Include

Download the minified engine file (pxl.min.js, ~44KB) or the development version (pxl.js) from GitHub and place it inside your project folder.

Include the script inside your HTML document's <head> tag. As soon as the script loads, it automatically registers Kilopixel's custom HTML Web Components (<pxl-stage>, <pxl-layer>, <pxl-circle>, etc.) with the browser.

<!-- Include Kilopixel in your document head -->
<script src="pxl.min.js"></script>
Download pxl.min.js (~44KB) Download Boilerplate (.zip)

2. Fullscreen Starter Boilerplate

Here is a complete, copy-pasteable starter template. It uses a tiny 4-line CSS reset in the <head> to remove browser margins and enable a sleek, fullscreen responsive canvas—without requiring external stylesheets or inline style attributes.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Kilopixel Starter</title>
  <script src="js/pxl.min.js"></script>
  <style>
    body {
      margin: 0;
      background: #0f172a;
      overflow: hidden;
    }
  </style>
</head>
<body>

  <!-- Responsive stage that fills the entire viewport -->
  <pxl-stage ratio="16 / 9">
    <pxl-layer>
      <pxl-grid stroke="#1e293b" major="4"></pxl-grid>
      <pxl-circle 
        x="500" 
        y="300" 
        r="80 + wave(2) * 20" 
        fill="#f97316">
      </pxl-circle>
    </pxl-layer>
  </pxl-stage>

</body>
</html>

3. Zero Web Server Required (Works 100% Offline)

Double-Click and Run Anywhere

Unlike most modern JavaScript frameworks or 3D libraries that require Node.js, bundlers, or a local web server just to display a page, Kilopixel has zero CORS or file-system restrictions. You can save index.html anywhere on your computer and double-click it to open directly in any browser via the file:// protocol at a full 60fps.
