CSS Filters

Kilopixel provides a unified, responsive API for CSS and Canvas filters that works seamlessly across shapes and layers. Learn how to apply blurs, drop shadows, color adjustments, and chained effects — effortlessly animated at 60fps.

Never Use Units!

By sticking to pure numbers (e.g., filter="blur(15)" or contrast(130)), you can seamlessly animate filters using math and time variables. The engine handles all the CSS units (px, %, deg) behind the scenes and automatically scales spatial filters with the stage.

Exception: If you choose to use JavaScript backticks (template literals) for string interpolation (e.g., filter="`blur(${t * 10}px)`"), your math and time variables are evaluated natively by JavaScript. Because this bypasses Kilopixel's formatting helpers, you must include the units (px, %, deg) manually so the final generated string is valid CSS.

Multiple Filters: To combine two or more filters, simply wrap them in a standard JavaScript array: filter="[blur(10), contrast(150)]". Single filters do not require an array (e.g., filter="blur(10)"). The engine automatically separates array items with spaces in the generated CSS.

1. Single Filters & Interactive Playground

You can apply any CSS filter helper directly to a shape or layer using the filter attribute. The example below features a multi-shape composition. Use the tabs and sliders to explore each filter in real time.

<pxl-stage ratio="5 / 3">
  <pxl-layer filter="blur(0)">
    <!-- Blue Card -->
    <pxl-rect x="500" y="300" w="280" h="280" rx="40" fill="#3b82f6" stroke="#2563eb" strokewidth="4"></pxl-rect>

    <!-- Orange Accent Circle -->
    <pxl-circle x="410" y="210" r="85" fill="#f97316" stroke="#ea580c" strokewidth="4"></pxl-circle>

    <!-- Emerald Badge Circle -->
    <pxl-circle x="570" y="370" r="55" fill="#10b981" stroke="#059669" strokewidth="4"></pxl-circle>
  </pxl-layer>
</pxl-stage>

2. Filters Reference

Kilopixel provides 10 built-in scope functions that map directly to standard CSS filters. All numbers are unitless and automatically formatted by the engine.

Spatial Filters (Stage Scaled)
blur(radius)
number >= 0 | expr default: 0
Applies a Gaussian blur. The radius is specified in 1000-width stage units and automatically scales with the canvas.
dropShadow(x, y, blur, color)
numbers | expr, color default: '#000'
Applies a silhouette drop shadow following the alpha channel of the shape. Offsets and blur radius are in stage units. Accepts any standard CSS color string (e.g. '#000', 'blue', or 'rgba(...)').
Color & Tone Filters (Percentages & Angles)
brightness(percent)
number >= 0 | expr default: 100
Adjusts the brightness. 100 is normal, 0 is completely black, and values above 100 brighten the element.
contrast(percent)
number >= 0 | expr default: 100
Adjusts the contrast. 100 is normal, 0 renders solid gray, and values above 100 increase contrast.
hueRotate(degrees)
0 - 360 | expr default: 0
Rotates colors around the color wheel in degrees. Perfect for continuous hue animations with t or loop().
saturate(percent)
number >= 0 | expr default: 100
Adjusts color saturation. 100 is normal, 0 is completely desaturated, and values above 100 create super-vivid colors.
grayscale(percent)
0 - 100 | expr default: 0
Converts colors to monochrome. 0 is full color, and 100 is completely grayscale.
invert(percent)
0 - 100 | expr default: 0
Inverts colors. 0 is normal, and 100 creates a complete photographic negative effect.
sepia(percent)
0 - 100 | expr default: 0
Applies a warm vintage sepia tint. 0 is normal color, and 100 is full sepia tone.
opacity(percent)
0 - 100 | expr default: 100
Adjusts overall transparency within the filter pipeline. 100 is fully opaque, and 0 is fully transparent.

3. Chaining Multiple Filters

To apply two or more filters simultaneously, pass them as a standard JavaScript array: filter="[filter1, filter2, ...]". The engine automatically separates them with spaces in the generated CSS.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Chained Filter Array -->
    <pxl-rect x="500" y="300" w="300" h="300" rx="44" fill="#ec4899" stroke="#db2777" strokewidth="4"
      filter="[blur(5), contrast(140), hueRotate(90)]"></pxl-rect>
  </pxl-layer>
</pxl-stage>

4. Shape vs. Layer Filtering

Kilopixel supports filters on both individual shapes and entire layers, with an important architectural distinction:

  • Shape-Level (<pxl-circle filter="...">): Applied directly to the HTML5 Canvas context (ctx.filter). The shape is filtered during drawing, allowing multiple overlapping shapes to each have their own independent filters.
  • Layer-Level (<pxl-layer filter="...">): Applied to the layer's <canvas> DOM element (canvas.style.filter). The browser's GPU composites the entire flattened canvas with zero CPU rasterization overhead.

CSS-Only Fast Path

When a <pxl-layer> only animates compositing properties (like filter, alpha, or blend) and no geometric transforms, Kilopixel activates the CSS-only fast path: it skips canvas clearing and child re-rendering completely, allowing the GPU to animate filters at continuous 60fps with zero redraw cost.

Groups Do Not Support Filters

The <pxl-group> element is a lightweight container dedicated strictly to structural grouping and spatial transforms (x, y, rotate, scale). It does not have a canvas buffer and does not support bitmap filtering. To filter multiple shapes together, wrap them in a <pxl-layer>.
