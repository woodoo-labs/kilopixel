Coordinate System

Understanding the coordinate system is the key to mastering Kilopixel. Unlike standard Canvas APIs which use physical pixels, Kilopixel uses a responsive, logic-based coordinate space designed for declarative markup.

1. The 1000-Unit Logical Canvas

To make graphics fully responsive without any media queries, every Kilopixel <pxl-stage> has a fixed logical width of 1000 units. The height is dynamically calculated based on the ratio attribute.

For a 5 / 3 stage, the height is 600. This means a shape at x="500" y="300" is always perfectly centered, regardless of the physical screen size.

<!-- Placing a shape exactly in the center of the canvas -->
<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-circle x="500" y="300" r="50" fill="#3b82f6"></pxl-circle>
  </pxl-layer>
</pxl-stage>

2. Relative Coordinates (Layer Translation)

Working in absolute coordinates can get messy. Instead, you can move the entire <pxl-layer>. If we center the layer at 500, 281, we can now place our shapes at 0, 0. This is fundamental for building complex scenes.

<!-- Centering the layer instead of the shape -->
<pxl-stage ratio="5 / 3">
  <pxl-layer x="500" y="300">
    <pxl-circle x="0" y="0" r="50" fill="#10b981"></pxl-circle>
  </pxl-layer>
</pxl-stage>

3. Pivot Points & Rotation

In standard HTML/CSS, coordinates usually refer to the top-left corner. In Kilopixel, x and y always define the absolute pivot point of the shape.

By default, shapes are centered exactly on this pivot. If you change a shape's anchor (e.g., anchor="top-left"), the shape shifts relative to the pivot, but any rotation (like rotate="t * 45") will still cleanly swing around that exact x,y point.

<!-- A square swinging around its top-left corner -->
<pxl-stage ratio="5 / 3">
  <pxl-layer x="500" y="300">
    <pxl-rect x="0" y="0" w="100" h="100" anchor="top-left" fill="#8b5cf6" rotate="t * 45"></pxl-rect>
  </pxl-layer>
</pxl-stage>

4. Local Offsets (dx & dy)

This is where Kilopixel's coordinate system shines. The dx and dy attributes apply a local offset after rotation and scaling.

By keeping the pivot point (x/y) fixed at the center, but offsetting the shape by dx="150", you can create perfect orbital mechanics mathematically effortlessly!

Use the sliders below to see how standard HTML inputs can instantly drive the Kilopixel canvas via the ref.* registry.

<!-- Standard HTML Inputs driving Kilopixel variables -->
<input type="range" oninput="pxl.nodes.demoOrbitOffset.set('value', this.value)">
<input type="range" oninput="pxl.nodes.demoOrbitSpeed.set('value', this.value)">

<!-- Kilopixel Variables -->
<pxl-var id="demoOrbitOffset" value="150"></pxl-var>
<pxl-var id="demoOrbitSpeed" value="90"></pxl-var>

<pxl-stage ratio="5 / 3">
  <pxl-layer x="500" y="300">
    <!-- The Sun (Pivot Point) -->
    <pxl-circle r="30" fill="#f59e0b"></pxl-circle>

    <!-- Orbiting Planet -->
    <pxl-circle 
      dx="ref.demoOrbitOffset.value" 
      rotate="t * ref.demoOrbitSpeed.value" 
      r="20" fill="#3b82f6">
    </pxl-circle>
  </pxl-layer>
</pxl-stage>
