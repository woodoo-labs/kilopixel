Coordinate System

Understanding the coordinate system is the key to mastering Kilopixel. Unlike standard Canvas APIs which use physical pixels, Kilopixel uses a responsive, logic-based coordinate space designed for declarative markup.

1. The 1000-Unit Logical Canvas

To make graphics fully responsive without any media queries, every Kilopixel <pxl-stage> has a fixed logical width of 1000 units. The height is dynamically calculated based on the ratio attribute.

For a ratio="5 / 3" stage, the height is 600. This means a shape at x="500" y="300" is always perfectly centered, regardless of the physical screen size.

<!-- Placing a shape exactly in the center of the canvas -->
<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-circle x="500" y="300" r="200" stroke="#FF8A65"></pxl-circle>
  </pxl-layer>
</pxl-stage>

2. Relative Coordinates (Layer Translation)

Working in global coordinates can quickly become difficult to manage. Instead, you can translate the entire <pxl-layer> to create a local coordinate space. This is a fundamental concept for building complex, movable scenes:

  • Global Positioning: The layer itself is positioned at x="500" y="300", placing its origin at the exact center of the global 1000-unit stage.
  • Local Origin: Because the shape lives inside the layer, the layer's center point acts as the local (0, 0) origin for the shape.
  • Independent Movement: If you drag the Layer sliders to move it, notice that the shape's x and y coordinates do not change. The shape physically moves across the screen because its parent layer is moving, but its local mathematical position remains strictly relative to the layer's origin.
<!-- Centering the layer instead of the shape -->
<pxl-stage ratio="5 / 3">
  <pxl-layer x="500" y="300">
    <pxl-circle x="200" y="150" r="300" stroke="#FF8A65"></pxl-circle>
  </pxl-layer>
</pxl-stage>

3. Basic Rotation around Layout Center

In Kilopixel, x and y define an element's layout center. By default (when no offset and no pivot is specified), any rotation or scaling is applied directly around this center coordinate (x, y).

Applying rotation is incredibly simple, but it's important to understand the difference between Layer and Shape rotation in the example below:

  • Layer Rotation: Rotating a <pxl-layer> tilts the entire coordinate grid beneath it. The shape's coordinates don't change, but the physical space it lives in spins around the layer's origin (0, 0).
  • Shape Rotation: Rotating a shape (like a <pxl-ellipse>) spins that specific shape around its own layout center (x, y), leaving the rest of the canvas untouched.
<!-- An ellipse spinning perfectly around its layout center -->
<pxl-stage ratio="5 / 3">
  <pxl-layer x="500" y="300" rotate="0">
    <pxl-ellipse 
      x="200" y="150" 
      rx="250" ry="100" 
      rotate="0" stroke="#FF8A65">
    </pxl-ellipse>
  </pxl-layer>
</pxl-stage>

4. Local Offsets (offsetX, offsetY)

This is where Kilopixel's coordinate system becomes incredibly powerful. The offsetX and offsetY attributes define a relative offset for the element's pivot point (invisible hinge) of rotation and scaling, moving it from the layout center (x, y) to (x + offsetX, y + offsetY).

Because this offset shifts the hinge point of the shape, any rotation applied will cause the shape to orbit around this new pivot coordinate instead of spinning in place.

<!-- A rectangle orbiting its offset pivot point -->
<pxl-stage ratio="5 / 3">
  <pxl-layer x="150" y="200" rotate="0">
    <pxl-rect 
      x="300" y="150" 
      offsetX="150" offsetY="150" 
      rotate="0" 
      w="100" h="100" stroke="#FF8A65">
    </pxl-rect>
  </pxl-layer>
</pxl-stage>

5. Absolute Pivot Points (pivotX, pivotY)

While offsetX and offsetY define a pivot hinge relative to a shape's center, the pivotX and pivotY attributes allow you to define an absolute pivot coordinate within the parent layer.

When unrotated (rotate="0"), the shape rests at (x, y). When rotated, the shape orbits around the absolute coordinate (pivotX, pivotY)!

<!-- A shape rotating around an absolute pivot coordinate -->
<pxl-stage ratio="5 / 3">
  <pxl-layer x="500" y="300" rotate="0">
    <pxl-rect 
      x="-200" y="-200" 
      pivotX="0" pivotY="0" 
      rotate="0" 
      w="100" h="100" fill="#ffedd5">
    </pxl-rect>
  </pxl-layer>
</pxl-stage>

6. Coordinate Mapping (toLocal)

The toLocal(target, property) function allows you to map any element's coordinates seamlessly into the local coordinate space of another element.

In this "constellation" example, two shapes orbit the center independently. The connecting line doesn't need to know any trigonometry—it simply uses toLocal to track the exact global position of the orbiting points and draw a perfectly connected line!

<!-- A line dynamically connecting independent points -->
<pxl-stage ratio="5 / 3">
  <pxl-layer x="500" y="300" rotate="0">
    <!-- Orbiting Points -->
    <pxl-circle id="pointA" x="-150" y="-200" offsetX="0" offsetY="200" rotate="0" r="15" fill="#3b82f6"></pxl-circle>
    <pxl-circle id="pointB" x="150" y="200" offsetX="0" offsetY="-200" rotate="0" r="15" fill="#f59e0b"></pxl-circle>

    <!-- Connecting Line -->
    <pxl-line 
      x1="toLocal(ref.pointA, 'x')" y1="toLocal(ref.pointA, 'y')" 
      x2="toLocal(ref.pointB, 'x')" y2="toLocal(ref.pointB, 'y')" 
      stroke="#94a3b8" strokewidth="2">
    </pxl-line>
  </pxl-layer>
</pxl-stage>

7. Animated Orbits

This is where Kilopixel's coordinate system shines. By combining local offsets with dynamic rotation, we can create perfect orbital mechanics mathematically effortlessly!

The offsetX attribute pushes the planet away from the Sun (the layout center at x and y), and the rotate attribute spins that entire offset vector around the center.

Use the sliders below to see how standard HTML inputs can instantly drive the Kilopixel canvas via the ref.* registry.

<!-- Standard HTML Inputs driving Kilopixel variables -->
<input type="range" oninput="pxl.nodes.ex7OrbitOffset.set('value', this.value)">
<input type="range" oninput="pxl.nodes.ex7OrbitSpeed.set('value', this.value)">

<pxl-stage ratio="5 / 3">
  <pxl-layer x="500" y="300">
    <!-- Kilopixel Variables -->
    <pxl-var id="ex7OrbitOffset" value="150"></pxl-var>
    <pxl-var id="ex7OrbitSpeed" value="90"></pxl-var>

    <!-- The Sun (Center Point) -->
    <pxl-circle r="30" fill="#f59e0b"></pxl-circle>

    <!-- Orbiting Planet -->
    <pxl-circle 
      offsetX="ref.ex7OrbitOffset.value" 
      rotate="t * ref.ex7OrbitSpeed.value" 
      r="20" fill="#3b82f6">
    </pxl-circle>
  </pxl-layer>
</pxl-stage>
