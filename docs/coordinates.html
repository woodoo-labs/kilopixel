Coordinate System

Understanding the coordinate system is the key to mastering Kilopixel. Unlike standard Canvas APIs which use physical pixels, Kilopixel uses a responsive, logic-based coordinate space designed for declarative markup.

1. The 1000-Unit Logical Canvas

To make graphics fully responsive without any media queries, every Kilopixel <pxl-stage> has a fixed logical width of 1000 units. The height is dynamically calculated based on the ratio attribute.

For a ratio="5 / 3" stage, the height is 600. This means a shape at x="500" y="300" is always perfectly centered, regardless of the physical screen size.

<!-- Placing a shape exactly in the center of the canvas -->
<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-circle x="500" y="300" r="50" fill="#ffedd5"></pxl-circle>
  </pxl-layer>
</pxl-stage>

2. Relative Coordinates (Layer Translation)

Working in absolute coordinates can get messy. Instead, you can move the entire <pxl-layer>. If we center the layer at x="500" y="300", we can now place our shapes at x="0" y="0". This is fundamental for building complex scenes.

<!-- Centering the layer instead of the shape -->
<pxl-stage ratio="5 / 3">
  <pxl-layer x="500" y="300">
    <pxl-circle x="0" y="0" r="50" fill="#ffedd5"></pxl-circle>
  </pxl-layer>
</pxl-stage>

3. Pivot Points (x, y) & Rotation

In Kilopixel, x and y always act as the absolute pivot point.

Because of this, applying rotation is incredibly simple. However, it's important to understand the difference between Layer and Shape rotation in the example below:

  • Layer Rotation: Rotating a <pxl-layer> tilts the entire coordinate grid beneath it. The shape's coordinates don't change, but the physical space it lives in spins around the Layer's origin.
  • Shape Rotation: Rotating a shape (like a <pxl-ellipse>) only spins that specific shape around its own local x, y pivot point, leaving the rest of the canvas untouched.
<!-- An ellipse spinning perfectly around its center point -->
<pxl-stage ratio="5 / 3">
  <pxl-layer x="500" y="300" rotate="0">
    <pxl-ellipse 
      x="0" y="0" 
      rx="100" ry="40" 
      rotate="0" fill="#ffedd5">
    </pxl-ellipse>
  </pxl-layer>
</pxl-stage>

4. Local Offsets (dx, dy)

This is where Kilopixel's coordinate system becomes incredibly powerful. The dx and dy attributes apply a local offset after rotation and scaling.

By keeping the pivot point fixed, but offsetting the shape by dx, any rotation applied will cause the shape to orbit the pivot point instead of just spinning in place.

<!-- A rectangle orbiting its pivot point -->
<pxl-stage ratio="5 / 3">
  <pxl-layer x="500" y="300" rotate="0">
    <pxl-rect 
      x="0" y="0" 
      dx="-200" dy="-200" 
      rotate="0" 
      w="100" h="100" fill="#ffedd5">
    </pxl-rect>
  </pxl-layer>
</pxl-stage>

5. Animated Orbits

This is where Kilopixel's coordinate system shines. The dx and dy attributes apply a local offset after rotation and scaling.

By keeping the pivot point (x/y) fixed at the center, but offsetting the shape by dx="150", you can create perfect orbital mechanics mathematically effortlessly!

Use the sliders below to see how standard HTML inputs can instantly drive the Kilopixel canvas via the ref.* registry.

<!-- Standard HTML Inputs driving Kilopixel variables -->
<input type="range" oninput="pxl.nodes.ex5OrbitOffset.set('value', this.value)">
<input type="range" oninput="pxl.nodes.ex5OrbitSpeed.set('value', this.value)">

<!-- Kilopixel Variables -->
<pxl-var id="ex5OrbitOffset" value="150"></pxl-var>
<pxl-var id="ex5OrbitSpeed" value="90"></pxl-var>

<pxl-stage ratio="5 / 3">
  <pxl-layer x="500" y="300">
    <!-- The Sun (Pivot Point) -->
    <pxl-circle r="30" fill="#f59e0b"></pxl-circle>

    <!-- Orbiting Planet -->
    <pxl-circle 
      dx="ref.ex5OrbitOffset.value" 
      rotate="t * ref.ex5OrbitSpeed.value" 
      r="20" fill="#3b82f6">
    </pxl-circle>
  </pxl-layer>
</pxl-stage>
