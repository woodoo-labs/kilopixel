Circle <pxl-circle>

A multi-mode radial primitive that renders circles, hollow rings, open arcs, curved diagram arrows, solid pie chart wedges, donut chart segments, and animated loading spinners — all from a single declarative tag.

1. Interactive Circle Sandbox

Experiment with the sliders below to see how a single <pxl-circle> element morphs across its different visual archetypes on a standard 1000 × 600 logical canvas.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-circle x="500" y="300" 
      r="180" 
      ir="0" 
      start="0" 
      sweep="270" 
      pie="false"
      stroke="#f97316"></pxl-circle>
  </pxl-layer>
</pxl-stage>

2. Attribute Specification

The table below covers all attributes supported by <pxl-circle>. Use the tabs to switch between circle-specific attributes and common attributes shared across all shapes.

r
default: 0 0–1000 | expr
Outer radius of the circle or arc in logical units. Supports dynamic time expressions like r="100 + wave(2)*20".
ir
default: 0 0–1000 | expr
Inner radius. When ir > 0, the interior is hollowed out to render concentric rings, donuts, or hollow arc bands.
start
default: 0 number | expr
Start angle in degrees (0° is at 3 o'clock / positive X-axis).
end
default: 360 number | expr
Absolute end angle in degrees. Note: If sweep is also specified, sweep takes priority and end is ignored.
sweep
default: 360 number | expr
Relative angular span in degrees from the start angle (e.g. start="45" sweep="90" draws from 45° to 135°). Takes priority over end.
pie
default: false false | true
When true, connects the endpoints of an open arc to the center origin (0, 0) to form a solid pie wedge.
anticlockwise
default: false false | true
When true, draws the circular arc counter-clockwise around the origin.
arrowstart
default: 0 'auto' | number
Draws a vector arrowhead at the starting point of an open arc curve. Use 'auto' to scale proportionally to stroke width.
arrowend
default: 0 'auto' | number
Draws a vector arrowhead at the ending point of an open arc curve. Use 'auto' to scale proportionally to stroke width.
arrowstyle
default: 'filled' 'filled' | 'line'
Visual appearance of open arc arrowheads ('filled' solid triangle vs. 'line' open vector v-shape).
fill
default: null color | gradient | expr
Fill color, CSS color string, or declarative gradient expression (e.g. fill="radial(1, ['#f97316', 'transparent'])").
stroke
default: null color | gradient | expr
Border stroke color or linear/radial gradient expression.
strokewidth
default: 1 0–100 | expr
Border thickness in logical units.
linecap
default: 'butt' 'butt' | 'round' | 'square'
Shape of the line endpoints for stroked open arcs and curves.
linejoin
default: 'miter' 'miter' | 'round' | 'bevel'
Corner join appearance when lines meet at sharp angles.
miterlimit
default: 10 number >= 1
Maximum ratio of miter length to stroke width before beveling sharp corners.
linedash
default: [] [dash, gap] | expr
Dash pattern array in logical units (e.g. linedash="[10, 5]" for 10px dash, 5px gap).
dashoffset
default: 0 number | expr
Phase shift offset of the line dash pattern. Animate with time t to create marching ants effects.
alpha
default: 1 0–1 | expr
Overall alpha transparency of the rendered shape (0 = invisible, 1 = fully opaque).
blend
default: 'source-over' 'multiply' | 'screen' | 'overlay'...
Supports all 26 Canvas 2D blend modes and clipping operations (e.g. 'multiply', 'screen', 'overlay', 'source-in'). See the MDN globalCompositeOperation Reference for interactive visual examples.
hidden
default: false false | true
When set to true, hides the shape from rendering.
filter
default: '' CSS filter string | expr
CSS visual filter string (e.g. filter="drop-shadow(0px 0px 15px rgba(249,115,22,0.8))"). Supports all CSS filter functions like blur(), brightness(), contrast(), and drop-shadow(). See the MDN Canvas filter Reference for all available functions.
x / y
default: 0 0–1000 | expr
Transform Origin & Center: The anchor point of the shape in logical stage coordinates.
dx / dy
default: 0 number | expr
Visual Displacement: Shifts the rendered geometry away from (x, y) without changing the rotation pivot.
ref.id.tx / ty
default: x + dx read-only JS getter
Total Coordinates: Read-only JS properties returning the combined total position (x + dx and y + dy).
rotate
default: 0 number | expr
Rotation around (x, y) in degrees (e.g. rotate="t * 90" for 90°/second continuous spin).
scale / scalex / scaley
default: 1 number | expr
Uniform or independent axis scaling factors.
skewx / skewy
default: 0 number | expr
Horizontal and vertical shear skew angles in degrees (typically -89 to 89 before infinite shearing at ±90).
onclick
default: null JS script
Fires when a complete click or tap sequence (down and release over the same shape) occurs. Works on mouse, touch, and stylus.
onenter
default: null JS script
Fires once when the pointer enters the shape. Recommended over legacy hover handlers.
onleave
default: null JS script
Fires once when the pointer exits the shape bounding area.
onmove
default: null JS script
Fires continuously as the pointer moves across the shape.
ondown
default: null JS script
Fires when the primary pointer button is pressed down while over the shape.
onup
default: null JS script
Fires when the primary pointer button is released while over the shape.

3. The Disc & The Ring r, ir

A simple outer radius (r) draws a solid disc. Providing an inner radius (ir > 0) hollows out the center to produce a concentric ring.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Solid Disc (ir = 0) -->
    <pxl-circle x="280" y="300" r="110" ir="0" fill="#f97316"></pxl-circle>

    <!-- Right: Hollow Ring (ir > 0) -->
    <pxl-circle x="720" y="300" r="110" ir="60" stroke="#3b82f6"></pxl-circle>
  </pxl-layer>
</pxl-stage>

4. Open Arcs & Animated Spinners start, sweep

By defining start and sweep angles in standard degrees (0°–360°) along with time-based expressions, a circle becomes an animated loading ring or progress gauge.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Animated Arc (Loading Spinner Mode) -->
    <pxl-circle x="500" y="300" r="140" 
      stroke="#f97316" 
      strokewidth="16" 
      start="t * 180" 
      sweep="160 + wave(3) * 120"
      filter="drop-shadow(0px 0px 15px rgba(249,115,22,0.8))"></pxl-circle>
  </pxl-layer>
</pxl-stage>

5. Pie Wedges & Donut Charts pie, ir

Setting pie="true" connects the ends of an open arc to the center origin (0, 0) to create solid wedges (like Pac-Man). Combining ir > 0 with sweep creates concentric donut chart segments.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Animated Pac-Man (Pie Wedge Mode) -->
    <pxl-circle x="280" y="300" r="110" 
      fill="#fde047" strokewidth="4"
      pie="true" 
      start="bounce(0.4) * 45" 
      sweep="360 - (bounce(0.4) * 90)"></pxl-circle>

    <!-- Right: Concentric Donut Chart Segments (ir > 0) -->
    <pxl-circle x="720" y="300" r="120" ir="70" fill="#fb7185" start="-90" sweep="135"></pxl-circle>
    <pxl-circle x="720" y="300" r="120" ir="70" fill="#c084fc" start="45" sweep="115"></pxl-circle>
    <pxl-circle x="720" y="300" r="120" ir="70" fill="#38bdf8" start="160" sweep="110"></pxl-circle>
  </pxl-layer>
</pxl-stage>

6. Curved Vector Arrows arrowstart, arrowend, arrowstyle

Adding arrowhead sizes to an open circular arc transforms it into a curved vector diagram arrow, circular dial, or speedometer indicator.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Filled Triangle Arrowhead (arrowstyle="filled") -->
    <pxl-circle x="280" y="300" r="100" strokewidth="12" stroke="#f97316" 
      start="-135" sweep="180" 
      arrowstart="auto" arrowend="auto" arrowstyle="filled"></pxl-circle>

    <!-- Open Line V-Arrowhead (arrowstyle="line") -->
    <pxl-circle x="720" y="300" r="100" strokewidth="12" stroke="#2563eb" 
      start="-45" sweep="180" 
      arrowstart="auto" arrowend="auto" arrowstyle="line"></pxl-circle>
  </pxl-layer>
</pxl-stage>

7. Pro Tips, Gotchas & Performance Best Practices

1. Angles are Always in Degrees (0°–360°)

Unlike standard Canvas 2D methods which require radians, Kilopixel evaluates all start, end, sweep, and rotate angles in standard degrees. Never multiply by Math.PI / 180 in your markup!

2. Compiler Fast-Path vs. Expression Evaluation

When you pass a raw number like r="100", Kilopixel hits a zero-cost compilation Fast-Path. Dynamic time expressions like r="100 + wave(2)*20" are compiled once and evaluated per animation frame.

3. Rotating Arcs vs. Changing Start/End

To rotate a circular gauge or spinner, use arc with a continuous rotation like rotate="t * 90" rather than manually recalculating moving start and end angles every frame.

4. Ellipses use <pxl-ellipse>

If you need independent horizontal and vertical radii (rx and ry), use the dedicated <pxl-ellipse> element rather than applying non-uniform scaling to a circle.
