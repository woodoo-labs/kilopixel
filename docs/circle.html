Circle

The circle shape renders discs, hollow rings, pie slices, and curved diagram arrows. It supports inner radii for donut shapes, open arcs, and customizable arrowheads.

1. Radius

A simple outer radius (r) draws a solid disc. Providing an inner radius (ir) hollows out the center to produce a concentric ring.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Solid Disc -->
    <pxl-circle x="300" y="300" fill="#ffedd566" stroke="#f97316" strokewidth="4"
      r="150">
    </pxl-circle>

    <!-- Right: Hollow Ring -->
    <pxl-circle x="700" y="300" fill="#dbeafe66" stroke="#3b82f6" strokewidth="4"
      r="150" ir="50">
    </pxl-circle>
  </pxl-layer>
</pxl-stage>

2. Sectors

Setting pie="true" connects the ends of an arc to the center point to create a solid pie slice. Combining an inner radius (ir) with a sweep or end angle automatically seals outer and inner arcs into a hollow donut wedge.

Sweep vs. End Angle

Kilopixel supports both relative spans and absolute destination angles: sweep defines a relative angular span from start (e.g. start="45" sweep="90" spans 90° to reach 135°), whereas end defines an absolute target angle. If both are specified on the same element, sweep takes priority and end is ignored.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Pie Slice (Sweep Mode) -->
    <pxl-circle x="300" y="300" fill="#ffedd566" stroke="#f97316"
      pie="true" r="150" strokewidth="10"
      start="0" sweep="270">
    </pxl-circle>

    <!-- Right: Donut Wedge (End Angle Mode) -->
    <pxl-circle x="700" y="300" fill="#dbeafe66" stroke="#3b82f6" strokewidth="4"
      pie="true" r="150" ir="80"
      start="0" end="270">
    </pxl-circle>
  </pxl-layer>
</pxl-stage>

3. Chords

By default, sweeping a partial circle creates an Open Chord: the interior is filled, but the stroke only follows the curved perimeter. Setting closed="true" explicitly connects the endpoints, forming a Closed Chord (a circular segment) where the stroke fully wraps around the straight edge.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Open Chord (Default) -->
    <pxl-circle x="300" y="300" strokewidth="10" fill="#ffedd566" stroke="#f97316"
      r="150" sweep="270">
    </pxl-circle>

    <!-- Right: Closed Chord (closed="true") -->
    <pxl-circle x="700" y="300" strokewidth="10" fill="#dbeafe66" stroke="#3b82f6"
      closed="true"
      r="150" sweep="180">
    </pxl-circle>
  </pxl-layer>
</pxl-stage>

4. Arcs

By simply omitting the fill attribute, you can use circles to draw un-filled, stroked curved lines. The base Shape class also supports linedash, allowing you to easily create dashed dials and technical gauges.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Simple Arc (Sweep Mode) -->
    <pxl-circle x="300" y="300" stroke="#f97316"
      r="150" strokewidth="10"
      start="0" sweep="180">
    </pxl-circle>

    <!-- Right: Dashed Arc (End Angle Mode) -->
    <pxl-circle x="700" y="300" stroke="#3b82f6" strokewidth="4"
      r="150" linedash="15"
      start="0" end="270">
    </pxl-circle>
  </pxl-layer>
</pxl-stage>

Controls

5. Arrowheads

Open arcs can be turned into curved arrows by adding arrowheads to either endpoint. Kilopixel supports filled triangles (arrowstyle="filled") and open chevrons (arrowstyle="line"), with automatic proportional scaling ('auto') or custom numeric sizing.

More on Arrowheads

For sizing, styles, and further examples, see the dedicated Arrowheads guide.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Auto-Sized Arrowheads -->
    <pxl-circle x="300" y="300" r="140" start="-45"
      sweep="270" stroke="#f97316"
      arrowstart="auto" arrowend="auto"
      strokewidth="10" arrowstyle="filled">
    </pxl-circle>

    <!-- Right: Custom-Sized Arrowheads -->
    <pxl-circle x="700" y="300" r="140" start="-45" sweep="270" stroke="#3b82f6"
      arrowstart="0" arrowend="35"
      strokewidth="6" arrowstyle="line">
    </pxl-circle>
  </pxl-layer>
</pxl-stage>

7. Element Reference

The table below covers all attributes, runtime properties, and event handlers supported by <pxl-circle>. Use the tabs to switch between circle-specific features and common APIs shared across all shapes.

Circle Geometry Attributes
r
number >= 0 | expr default: 0
Outer radius of the circle or arc.
ir
number >= 0 | expr default: 0
Inner radius. When ir > 0, the interior is hollowed out to render concentric rings, donuts, or hollow arc bands.
start
number | expr default: 0
Start angle in degrees (0° is at 3 o'clock / positive X-axis).
end
number | expr default: null
End angle in degrees. Defaults to null (if neither end nor sweep is specified, a full 360° circle is drawn). If sweep is also specified, sweep takes priority and end is ignored.
sweep
number | expr default: null
Relative angular span in degrees from the start angle (e.g. start="45" sweep="90" draws from 45° to 135°). Defaults to null (full 360° circle). Takes priority over end.
pie
false | true default: false
When true, connects the endpoints of an open arc to the center point to form a solid pie wedge. This mode is ignored if an inner radius (ir) is applied.
closed
false | true default: false
When true, connects the endpoints of an open arc with a straight chord, so the stroke wraps around the straight edge (a circular segment).
anticlockwise
false | true default: false
When true, draws the circular arc counter-clockwise around the origin.
Arrowhead Decorations
arrowstart
'auto' | number default: 0
Draws an arrowhead at the starting point of an open arc curve. Use 'auto' to automatically scale the size to strokewidth * 3.6.
arrowend
'auto' | number default: 0
Draws an arrowhead at the ending point of an open arc curve. Use 'auto' to automatically scale the size to strokewidth * 3.6.
arrowstyle
'filled' | 'line' default: 'filled'
Visual appearance of open arc arrowheads ('filled' solid triangle vs. 'line' open v-shape).
