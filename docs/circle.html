Shapes API

The Shapes API allows you to draw and manipulate various geometric primitives natively within your declarative layers.

HTML Syntax

You can create elements purely through HTML. Every shape has built-in coordinate logic (x, y, dx, dy) and natively evaluates mathematical expressions.

<pxl-stage ratio="16 / 9">
  <pxl-layer>
    <pxl-grid stroke="#f1f5f9" major="2" labels="true"></pxl-grid>
    <pxl-circle x="500" y="200" r="50" fill="red"></pxl-circle>
    <pxl-rect x="200" y="200" w="100" h="100" fill="blue"></pxl-rect>
  </pxl-layer>
</pxl-stage>

Javascript Interactivity

Because Kilopixel uses a zero-GC flat registry for all elements with an ID, you can instantly modify them via Javascript without needing to query the DOM.

// Update coordinates instantly outside the DOM using .set()
pxl.nodes.myCircle.set('x', 600);
pxl.nodes.myCircle.set('fill', 'green');

// Or use standard DOM APIs if you prefer
const rect = document.querySelector('pxl-rect');
rect.setAttribute('rotate', '45');

Advanced Highlighting Examples

Highlighting Specific Words

Using the KeepMarkup plugin, you can wrap any word in a <mark> tag right in your HTML, and Prism will preserve it.

<pxl-stage id="main" ratio="16 / 9">
  <pxl-layer>
    <pxl-circle x="500" y="200" r="50"></pxl-circle>
  </pxl-layer>
</pxl-stage>
