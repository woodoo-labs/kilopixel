<pxl-circle>

A multi-mode radial primitive that renders circles, hollow rings, open arcs, curved diagram arrows, solid pie chart wedges, donut chart segments, and animated loading spinners—all from a single declarative tag.

Inheritance: Shape → <pxl-circle>

2. Declarative Attribute Reference

The table below covers all attributes supported by <pxl-circle>. Use the tabs to switch between shape-specific attributes and those inherited from Shape.

Attribute Type Default Description
r number / expr 0 Outer radius of the circle or arc in logical units. Supports dynamic time expressions like r="100 + wave(2)*20".
ir number / expr 0 Inner radius. When ir > 0, the interior is hollowed out to render concentric rings, donuts, or hollow arc bands.
start number / expr 0 Start angle in degrees (0° is at 3 o'clock / positive X-axis).
end number / expr null Absolute end angle in degrees. If neither end nor sweep is provided, renders a full 360° circle.
sweep number / expr null Relative angular span in degrees from the start angle (e.g. start="45" sweep="90" draws from 45° to 135°).
pie boolean false When true, connects the endpoints of an open arc to the center origin (0, 0) to form a solid pie wedge.
anticlockwise boolean false When true, draws the circular arc counter-clockwise around the origin.
arrowstart number / 'auto' 0 Draws a vector arrowhead at the starting point of an open arc curve. Use 'auto' to scale proportionally to stroke width.
arrowend number / 'auto' 0 Draws a vector arrowhead at the ending point of an open arc curve. Use 'auto' to scale proportionally to stroke width.
arrowstyle string 'filled' Visual appearance of open arc arrowheads ('filled' solid triangle vs. 'line' open vector v-shape).
Attribute Type Default Description
fill string / expr 'transparent' Fill color, CSS color string, or declarative gradient expression (e.g. fill="radial(1, ['#f97316', 'transparent'])").
stroke string / expr 'transparent' Border stroke color or linear/radial gradient expression.
strokewidth number 1 Border thickness in logical units.
linedash array string [] Dashed border pattern in logical units (e.g. linedash="[10, 5]").
opacity / alpha number (0–1) 1 Global element transparency multiplier.
filter string / expr '' CSS visual filter string (e.g. filter="drop-shadow(0px 0px 15px rgba(249,115,22,0.8))").
shadowcolor string 'transparent' Native Canvas 2D shadow color.
shadowblur number 0 Native Canvas 2D shadow Gaussian blur radius in logical units.
shadowx / shadowy number 0 Horizontal and vertical shadow offsets in logical units.
Attribute Type Default Description
x / y number / expr 0 Transform Origin & Center: The anchor point of the shape in logical stage coordinates.
dx / dy number / expr 0 Visual Displacement: Shifts the rendered geometry away from (x, y) without changing the rotation pivot.
tx / ty number / expr 0 Texture Origin: Offsets pattern and gradient coordinates relative to the shape center.
rotate number / expr 0 Rotation around (x, y) in degrees (e.g. rotate="t * 90" for 90°/second continuous spin).
scale / scalex / scaley number / expr 1 Uniform or independent axis scaling factors.
skewx / skewy number / expr 0 Horizontal and vertical shear skew angles in degrees.
cursor string 'default' Mouse cursor displayed when hovering over the shape bounding box (e.g. 'pointer', 'move').
Attribute Type Default Description
onenter string (script) null Fires once when the pointer enters the shape. Recommended over legacy hover handlers.
onleave string (script) null Fires once when the pointer exits the shape bounding area.
onmove string (script) null Fires continuously as the pointer moves across the shape.
ondown string (script) null Fires when the primary pointer button is pressed down while over the shape.
onup string (script) null Fires when the primary pointer button is released while over the shape.

3. The 5 Visual Modes (Interactive Cookbook)

Because <pxl-circle> can render everything from solid discs to animated donut charts and curved vector arrows, we organize its real-world usage into 5 Visual Modes.

Mode 1: The Disc & The Ring (r vs. ir)

A simple outer radius (r) draws a solid disc. Providing an inner radius (ir > 0) hollows out the center to produce a concentric ring.

Mode 1 Controls

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Solid Disc (ir = 0) -->
    <pxl-circle x="280" y="300" r="110" ir="0" fill="#ffedd566" stroke="#f97316" strokewidth="6"></pxl-circle>

    <!-- Right: Hollow Ring (ir > 0) -->
    <pxl-circle x="720" y="300" r="110" ir="60" fill="#dbeafe66" stroke="#3b82f6" strokewidth="6"></pxl-circle>
  </pxl-layer>
</pxl-stage>

Mode 2: Open Arcs & Animated Spinners (start, sweep)

By defining start and sweep angles in standard degrees (0°–360°) along with time-based expressions, a circle becomes an animated loading ring or progress gauge.

Mode 2 Controls

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Background Track Ring -->
    <pxl-circle x="500" y="300" r="140" stroke="#cbd5e1" strokewidth="16"></pxl-circle>

    <!-- Glowing Animated Arc -->
    <pxl-circle x="500" y="300" r="140" 
      stroke="#14b8a6" 
      strokewidth="16" 
      start="t * 180" 
      sweep="160 + wave(3) * 120"
      filter="drop-shadow(0px 0px 15px rgba(20,184,166,0.8))"></pxl-circle>

    <!-- Orbiting Satellite Dot -->
    <pxl-circle x="500 + cos(t*3)*180" y="300 + sin(t*3)*180" r="10" fill="#0f766e"></pxl-circle>
  </pxl-layer>
</pxl-stage>

Mode 3: Pie Wedges & Donut Charts (pie="true" vs. ir > 0)

Setting pie="true" connects the ends of an open arc to the center origin (0, 0) to create solid wedges (like Pac-Man). Combining ir > 0 with sweep creates concentric donut chart segments.

Mode 3 Controls

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Animated Pac-Man (Pie Wedge Mode) -->
    <pxl-circle x="280" y="300" r="110" 
      fill="#fde047" stroke="#ca8a04" strokewidth="4"
      pie="true" 
      start="bounce(0.4) * 45" 
      sweep="360 - (bounce(0.4) * 90)"></pxl-circle>

    <!-- Right: Concentric Donut Chart Segments (ir > 0) -->
    <pxl-circle x="720" y="300" r="120" ir="70" fill="#fb7185" start="-90" sweep="135"></pxl-circle>
    <pxl-circle x="720" y="300" r="120" ir="70" fill="#c084fc" start="45" sweep="115"></pxl-circle>
    <pxl-circle x="720" y="300" r="120" ir="70" fill="#38bdf8" start="160" sweep="110"></pxl-circle>
  </pxl-layer>
</pxl-stage>

Mode 4: Curved Vector Arrows (arrowstart, arrowend, arrowstyle)

Adding arrowhead sizes to an open circular arc transforms it into a curved vector diagram arrow, circular dial, or speedometer indicator.

Mode 4 Controls

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Filled Triangle Arrowhead (arrowstyle="filled") -->
    <pxl-circle x="280" y="300" r="100" strokewidth="12" stroke="#0d9488" 
      start="-135" sweep="180" 
      arrowstart="auto" arrowend="auto" arrowstyle="filled"></pxl-circle>

    <!-- Open Line V-Arrowhead (arrowstyle="line") -->
    <pxl-circle x="720" y="300" r="100" strokewidth="12" stroke="#2563eb" 
      start="-45" sweep="180" 
      arrowstart="auto" arrowend="auto" arrowstyle="line"></pxl-circle>
  </pxl-layer>
</pxl-stage>

Mode 5: Transform Origin & Orbiting ((x, y) vs. (dx, dy))

Coordinates (x, y) always define the rotation anchor point. Applying visual displacement offsets (dx, dy) shifts the shape away from its pivot, creating orbiting satellites when rotate is animated.

Mode 5 Controls

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Central Origin Dot at (500, 300) -->
    <pxl-circle x="500" y="300" r="20" fill="#6d28d9"></pxl-circle>

    <!-- Satellite Orbiting around (500, 300) via dx/dy + rotate -->
    <pxl-circle x="500" y="300" 
      dx="160" dy="0" 
      r="30" 
      fill="#ffedd566" stroke="#f97316" strokewidth="6"
      rotate="t * 90"></pxl-circle>
  </pxl-layer>
</pxl-stage>

4. Pro Tips, Gotchas & Performance Best Practices

1. Angles are Always in Degrees (0°–360°)

Unlike standard Canvas 2D methods which require radians, Kilopixel evaluates all start, end, sweep, and rotate angles in standard degrees. Never multiply by Math.PI / 180 in your markup!

2. Compiler Fast-Path vs. Expression Evaluation

When you pass a raw number like r="100", Kilopixel hits a zero-cost compilation Fast-Path. Dynamic time expressions like r="100 + wave(2)*20" are compiled once and evaluated per animation frame.

3. Rotating Arcs vs. Changing Start/End

To rotate a circular gauge or spinner, use arc with a continuous rotation like rotate="t * 90" rather than manually recalculating moving start and end angles every frame.

4. Ellipses use <pxl-ellipse>

If you need independent horizontal and vertical radii (rx and ry), use the dedicated <pxl-ellipse> element rather than applying non-uniform scaling to a circle.
