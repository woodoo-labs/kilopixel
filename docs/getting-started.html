Getting Started

Kilopixel is designed to be completely frictionless. There are no build tools, bundlers, or complicated initializations required. It works instantly in any modern browser.

Installation

Simply include the minified script in the <head> of your HTML file:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Scene</title>
  <script src="pxl.min.js"></script>
</head>
<body>
  <!-- Your Scene goes here -->
</body>
</html>

Your First Scene

Every Kilopixel graphic starts with a Stage, which manages the underlying Canvas element. Inside the stage, you add Layers, and inside Layers, you add Shapes.

<!-- 1. Define the Stage -->
<pxl-stage id="main">
  
  <!-- 2. Define a rendering context -->
  <pxl-layer>
    
    <!-- 3. Add a shape -->
    <pxl-circle 
      x="500" 
      y="500" 
      radius="100" 
      fill="red" 
    />
    
  </pxl-layer>
</pxl-stage>

Adding Animation

Attributes aren't just static strings—they evaluate mathematical expressions at 60 frames per second. The engine exposes a time variable t (in seconds) and built-in drivers like wave().

Let's make our circle breathe and change color dynamically:

<pxl-circle 
  x="500" 
  y="500" 
  radius="100 + wave(2) * 50" 
  fill="t % 2 < 1 ? 'red' : 'blue'" 
/>
  • wave(2) returns a sine wave oscillating between -1 and 1 over a 2-second period.
  • t represents the time in seconds since the stage started rendering.
