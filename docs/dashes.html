Dashes

Create dashed outlines and animated marching patterns across any Kilopixel shape. Use linedash to specify repeating dash-and-gap sequences and dashoffset to phase-shift or animate borders at 60 frames per second.

The Dash Array Standard

Following the HTML5 Canvas specification, linedash accepts a list of lengths describing alternating dashes and empty gaps (e.g., [dash, gap] or [dash, gap, dot, gap]). Kilopixel automatically repeats the sequence around the entire perimeter of closed shapes and open lines alike.

1. Dashed Strokes & Offset

The linedash and dashoffset attributes allow you to create patterned, dashed outlines across any Kilopixel shape. Rather than drawing a continuous path, the stroke alternates between drawn dash segments and empty gaps.

  • Dash Pattern: The linedash attribute accepts a JavaScript array of numbers defining alternating dash and gap lengths (e.g., linedash="[24, 16]"). As a fast-path, a single number without brackets (e.g., linedash="24") is also supported to create an equal repeating dash and gap.
  • Phase Shift: The dashoffset attribute shifts where the pattern begins along the path perimeter, enabling precise alignment or manual sliding.
<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- 1. Circle with Dash & Gap Spacing -->
    <pxl-circle x="300" y="300" r="140" stroke="#f97316" strokewidth="20" linecap="butt" fill="none"
      linedash="[24, 28]"
      dashoffset="0">
    </pxl-circle>

    <!-- 2. Polyline with Pattern Presets -->
    <pxl-polyline points="520,300; 640,180; 760,420; 880,300" smooth="1" stroke="#3b82f6" strokewidth="12" linecap="round" fill="none"
      linedash="[44, 28, 10, 28, 10, 28]"
      dashoffset="0">
    </pxl-polyline>
  </pxl-layer>
</pxl-stage>

2. Marching Ants & Continuous Animation

Combining linedash with a dynamic dashoffset expression produces continuous stroke animation — commonly known as marching ants. By multiplying the framework's time driver t by a velocity coefficient (e.g. dashoffset="-t * 40"), the dash pattern advances smoothly along the path perimeter at 60fps.

Directionality & Flow

A negative offset rate (-t * speed) advances the pattern forward along the path — moving clockwise around closed boundaries and from start to end along open paths. A positive offset rate (t * speed) reverses the flow direction.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- 1. Selection Marquee (Closed Rect) -->
    <pxl-rect x="300" y="300" w="280" h="280"
      stroke="#f97316" strokewidth="4" fill="#ffedd522"
      linedash="[12, 12]"
      dashoffset="-t * 40">
    </pxl-rect>

    <!-- 2. Signal Conduit (Dormant Wire + Animated Pulse Runner) -->
    <pxl-polyline points="520,300; 640,180; 760,420; 880,300" smooth="1"
      stroke="#1e3a8a33" strokewidth="20" linecap="round" fill="none">
    </pxl-polyline>
    <pxl-polyline points="520,300; 640,180; 760,420; 880,300" smooth="1"
      stroke="#3b82f6" strokewidth="20" linecap="round" fill="none"
      linedash="[40, 80]"
      dashoffset="-t * 60">
    </pxl-polyline>
  </pxl-layer>
</pxl-stage>
