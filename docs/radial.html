Radial Gradient

Radial gradients (radial()) spread colors outward from a center point in circles. They are used for circular color fills, spotlights, and lighting effects.

Bounding Box & colorsArray

Radial gradients map to the shape's bounding box (where top-left is (0, 0) and bottom-right is (1, 1)) and share the universal colorsArray parameter. If you are new to Kilopixel gradients, review the visual diagram in Linear Gradient first.

1. Radial Gradient (1-Value Mode)

The 1-value mode is the simplest form of the radial gradient. In this mode, the gradient is automatically centered at the shape's bounding box center (0.5, 0.5).

1-Value Mode Syntax

fill="radial([r1], colorsArray)"

The parameter r1 defines the outer radius circle and supports two distinct modes:

  • Numeric Radius: A number, measured like a circle's r. The gradient circle keeps its size whatever the shape's width or height (e.g., r1 = 200).
  • Keyword Radius: A responsive boundary that dynamically calculates distance and snaps to the shape's edges or corners (e.g., r1 = 'top-right').

In this example, select a keyword anchor or switch to numeric mode to see how the gradient expands outward from the center (0.5, 0.5). The dashed pink circle represents the calculated radius boundary.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-rect x="500" y="300"
      w="400" h="250"
      rotate="0"
      fill="radial(['top-right'], ['#f8fafc', '#475569'])">
    </pxl-rect>
  </pxl-layer>
</pxl-stage>

2. Radial Gradient (3-Value Mode)

The 3-value mode allows you to position the gradient origin anywhere within (or beyond) the shape's bounding box. You explicitly define the origin by setting Center 0 (x0, y0), followed by the boundary Radius 1 (r1).

3-Value Mode Syntax

fill="radial([x0, y0, r1], colorsArray)"

The parameters x0 and y0 define the center of the gradient using normalized bounding box coordinates (from 0 to 1).

The parameter r1 defines the outer radius circle and supports two distinct modes:

  • Numeric Radius: A number, measured like a circle's r. The gradient circle keeps its size whatever the shape's width or height (e.g., r1 = 200).
  • Keyword Radius: A responsive boundary that dynamically calculates distance from (x0, y0) and snaps to the shape's edges or corners (e.g., r1 = 'top-right').

In this example, move the gradient center with the Gradient x0 and Gradient y0 sliders, and select a keyword anchor or switch to numeric mode to see how the gradient radiates outward from the custom center point. The dashed pink circle represents the calculated radius boundary.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-rect x="500" y="300"
      w="400" h="250"
      rotate="0"
      fill="radial([0.3, 0.3, 'top-right'], ['#f8fafc', '#475569'])">
    </pxl-rect>
  </pxl-layer>
</pxl-stage>

3. Radial Gradient (6-Value Mode)

The 6-value mode is the full form of the canvas radial gradient: two independent circles, a Start Circle (x0, y0, r0) and an End Circle (x1, y1, r1).

Inside the start circle, the shape is filled with the first color; between the two circles, the colors blend from the first to the last. Moving the circles apart gives spotlights, cones, spherical shading and crescents.

6-Value Mode Syntax

fill="radial([x0, y0, r0, x1, y1, r1], colorsArray)"

Both r0 and r1 can be a number, measured like a circle's r, or a keyword such as 'top', 'closest-side' or 'farthest-corner'. Try adjusting the centers and radii of both circles to see how the two independent focal boundaries interact.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-rect x="500" y="300"
      w="400" h="300"
      rotate="0"
      fill="radial([0.3, 0.3, 40, 0.6, 0.6, 200], ['#f8fafc', '#475569'])">
    </pxl-rect>
  </pxl-layer>
</pxl-stage>
