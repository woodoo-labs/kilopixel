Radial Gradient

Kilopixel offers highly flexible radial gradients for circular color fills, spotlights, and lighting effects.

To work with gradients in Kilopixel, you first need to understand two core concepts: the Bounding Box and the colorsArray.

Bounding Box: In Kilopixel, all gradients are mapped to an element's invisible bounding box. The top-left corner of any shape is always exactly (0, 0), and the bottom-right is (1, 1). This guarantees that if you move, scale, or stretch your shape, the gradient stretches seamlessly with it — no complex trigonometry required!

In the diagrams below, the blue coordinates represent the fixed corners of the shape's invisible 0-to-1 bounding box space.

colorsArray: All gradients in Kilopixel share a common parameter called colorsArray to define their colors. You can provide this array in two ways:

  • Colors Only: Pass an array of just colors (e.g., ['red', 'yellow', 'blue']). Kilopixel will automatically space them out evenly from 0 to 1.
  • Color Stops: Pass an array alternating between numeric offsets (0 to 1) and colors for precise control (e.g., [0, 'red', 0.8, 'blue']).

1. Radial Gradient (1-Value Mode)

The 1-value mode is the simplest form of the radial gradient. In this mode, the gradient is automatically centered at the shape's bounding box center (0.5, 0.5).

1-Value Mode Syntax

fill="radial([r1], colorsArray)"

The parameter r1 defines the outer radius circle and supports two distinct modes:

  • Numeric Radius: An absolute radius in layer coordinates, behaving just like a circle's r attribute. It produces an isotropic circle of light that maintains its exact size regardless of the shape's width or height (e.g., r1 = 200).
  • Keyword Radius: A responsive boundary that dynamically calculates distance and snaps to the shape's edges or corners (e.g., r1 = 'top-right').

In this example, select a keyword anchor or switch to numeric mode to see how the gradient expands outward from the center (0.5, 0.5). The dashed purple circle represents the calculated radius boundary.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-rect 
      x="500" y="300"
      w="400" h="250" 
      rotate="0"
      fill="radial(['top-right'], ['#e2e8f0', '#475569'])">
    </pxl-rect>
  </pxl-layer>
</pxl-stage>

2. Radial Gradient (3-Value Mode)

The 3-value mode allows you to position the gradient origin anywhere within (or beyond) the shape's bounding box. You explicitly define the origin by setting Center 0 (x0, y0), followed by the boundary Radius 1 (r1).

3-Value Mode Syntax

fill="radial([x0, y0, r1], colorsArray)"

The parameters x0 and y0 define the center of the gradient using normalized bounding box coordinates (from 0 to 1).

The parameter r1 defines the outer radius circle and supports two distinct modes:

  • Numeric Radius: An absolute radius in layer coordinates, behaving just like a circle's r attribute. It produces an isotropic circle of light that maintains its exact size regardless of the shape's width or height (e.g., r1 = 200).
  • Keyword Radius: A responsive boundary that dynamically calculates distance from (x0, y0) and snaps to the shape's edges or corners (e.g., r1 = 'top-right').

In this example, adjust the gradient origin with the Center X0 and Center Y0 sliders, and select a keyword anchor or switch to numeric mode to see how the gradient radiates outward from the custom center point. The dashed purple circle represents the calculated radius boundary.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-rect 
      x="500" y="300"
      w="400" h="250" 
      rotate="0"
      fill="radial([0.3, 0.3, 'top-right'], ['#e2e8f0', '#475569'])">
    </pxl-rect>
  </pxl-layer>
</pxl-stage>

3. Radial Gradient (6-Value Mode)

The 8-value mode unlocks the full power of the native HTML5 Canvas radial gradient. In this mode, you define two completely independent circles: a Start Circle (cx0, cy0, rx0, ry0) and an End Circle (cx1, cy1, rx1, ry1).

This allows you to give the inner circle (Start Circle) a physical volume. The space inside the Start Circle is filled with the 0% color stop, and the gradient smoothly interpolates through the space between the two circles. This is perfect for advanced lighting, masking, or crescent moon effects.

8-Value Mode Syntax: (Normalized coordinates)

fill="radial([cx0, cy0, rx0, ry0, cx1, cy1, rx1, ry1], colorsArray)"

In this example, drag the coordinates for the Start Circle and End Circle independently. The purple coordinates represent the gradient, while the blue coordinates represent the fixed bounding box. Notice how giving the Start Circle a radius creates a solid inner core before the gradient begins.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-rect 
      x="500" y="300"
      w="500" h="500" 
      rotate="0"
      fill="radial([0.5, 0.2, 0.7, 0.2, 0.5, 0.5, 1, 0.5], ['#e2e8f0', '#475569'])">
    </pxl-rect>
  </pxl-layer>
</pxl-stage>
