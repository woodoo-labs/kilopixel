Radial Gradient

Kilopixel offers highly flexible radial gradients for circular and elliptical color fills.

To work with gradients in Kilopixel, you first need to understand two core concepts: the Bounding Box and the colorsArray.

Bounding Box: In Kilopixel, all gradients are mapped to an element's invisible bounding box. The top-left corner of any shape is always exactly (0, 0), and the bottom-right is (1, 1). This guarantees that if you move, scale, or stretch your shape, the gradient stretches seamlessly with it — no complex trigonometry required!

In the diagrams below, the blue coordinates represent the fixed corners of the shape's invisible 0-to-1 bounding box space.

colorsArray: All gradients in Kilopixel share a common parameter called colorsArray to define their colors. You can provide this array in two ways:

  • Colors Only: Pass an array of just colors (e.g., ['red', 'yellow', 'blue']). Kilopixel will automatically space them out evenly from 0 to 1.
  • Color Stops: Pass an array alternating between numeric offsets (0 to 1) and colors for precise control (e.g., [0, 'red', 0.8, 'blue']).

1. Radial Gradient (1-Value Mode)

The 1-value mode is the simplest form of the radial gradient, defined as radial([r1], colorsArray). In this mode, the gradient is automatically centered at the shape's bounding box center (0.5, 0.5) with an inner start radius of 0.

The parameter r1 defines the outer radius circle. When provided as a number, it represents a scalar radius relative to the shape's bounding box width (calculated as r1 × width). Because the radius is derived mathematically, the gradient maintains a perfectly circular shape that scales proportionally with the element.

1-Value Mode Syntax

Provide a single radius value (number or keyword) in the configuration array:

fill="radial([r1], colorsArray)"

In this example, drag the radius slider to see how the gradient expands outward from the center (0.5, 0.5). The dashed purple circle represents the calculated radius boundary.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-rect 
      x="500" y="300"
      w="400" h="250" 
      rotate="0"
      fill="radial([0.5], ['#e2e8f0', '#475569'])">
    </pxl-rect>
  </pxl-layer>
</pxl-stage>

2. Radial Gradient (3-Value Mode)

The 4-value mode allows you to move the gradient's origin away from the default (0.5, 0.5). You explicitly define the origin by setting Center 0 (cx0, cy0), followed by the boundary Radius 1 (rx1, ry1).

The Euclidean distance logic remains exactly the same, but the radius is now calculated between your custom Center 0 point and the Radius 1 point. This is incredibly useful for off-center highlights, lighting effects, or matching a gradient's origin to a specific focal point in your UI.

4-Value Mode Syntax: (Normalized coordinates)

fill="radial([cx0, cy0, rx1, ry1], colorsArray)"

In this example, drag both the Center 0 coordinates (cx0, cy0) and the Radius 1 coordinates (rx1, ry1). Notice how the dashed radius circle follows Center 0, while its total size is determined by the physical distance to the Radius 1 point.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-rect 
      x="500" y="300"
      w="400" h="250" 
      rotate="0"
      fill="radial([0.3, 0.3, 1, 1], ['#e2e8f0', '#475569'])">
    </pxl-rect>
  </pxl-layer>
</pxl-stage>

3. Radial Gradient (6-Value Mode)

The 8-value mode unlocks the full power of the native HTML5 Canvas radial gradient. In this mode, you define two completely independent circles: a Start Circle (cx0, cy0, rx0, ry0) and an End Circle (cx1, cy1, rx1, ry1).

This allows you to give the inner circle (Start Circle) a physical volume. The space inside the Start Circle is filled with the 0% color stop, and the gradient smoothly interpolates through the space between the two circles. This is perfect for advanced lighting, masking, or crescent moon effects.

8-Value Mode Syntax: (Normalized coordinates)

fill="radial([cx0, cy0, rx0, ry0, cx1, cy1, rx1, ry1], colorsArray)"

In this example, drag the coordinates for the Start Circle and End Circle independently. The purple coordinates represent the gradient, while the blue coordinates represent the fixed bounding box. Notice how giving the Start Circle a radius creates a solid inner core before the gradient begins.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-rect 
      x="500" y="300"
      w="500" h="500" 
      rotate="0"
      fill="radial([0.5, 0.2, 0.7, 0.2, 0.5, 0.5, 1, 0.5], ['#e2e8f0', '#475569'])">
    </pxl-rect>
  </pxl-layer>
</pxl-stage>
