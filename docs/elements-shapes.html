Elements and Shapes

Kilopixel provides a comprehensive set of declarative HTML elements representing a scene graph and drawing primitives.

The Scene Graph

<pxl-stage>

The root container. You can have multiple independent stages on a single webpage.

  • ratio (default 16/9): Sets the CSS aspect ratio of the stage.
  • id: Required if you want to reference the stage properties (e.g., id="main").

<pxl-layer>

A compositing layer that owns its own <canvas>.

  • Extremely efficient. If a layer is static, it doesn't re-render.
  • Support blend modes, filters, and global opacity.
  • Layers are stacked in their DOM order.

<pxl-group>

A nestable container for transforms.

  • Groups do not own a canvas; they draw directly into their parent layer's canvas.
  • Transforms (rotate, scale, dx, dy) and opacity (alpha) compound down the hierarchy.

Shape Primitives

All shapes share common properties: x, y, dx, dy, rotate, scale, alpha, fill, stroke, linewidth, linedash, filter, blend.

<pxl-circle>

Draws circles, arcs, pies, and donuts.

  • Attributes: r (radius), ir (inner radius for donuts), start & end (angles in degrees for arcs), sweep, pie, arrowstart/end/style.

<pxl-ellipse>

Like a circle, but with independent x/y radii.

  • Attributes: rx, ry, irx, iry, plus all arc and pie attributes from circle.

<pxl-rect>

Draws rectangles with advanced corner radiuses and anchoring.

  • Attributes: w (width), h (height), anchor (9-position system: center, topleft, bottom, etc.).
  • Corner Radii: r (all corners) or r1, r2, r3, r4 for individual corners.

<pxl-line>

Draws a straight line between two points.

  • Attributes: x1, y1, x2, y2, repeat (for line tiling), arrowstart/end/style.

<pxl-polyline>

Draws a series of connected points, with optional Catmull-Rom smoothing.

  • Attributes: points (comma-separated list), closed, smooth, mode (relative/absolute).
  • Per-Coordinate Animation: When you bind an expression to points, each individual coordinate value (p0, p1, p2...) is compiled independently, allowing for highly complex morphing and kinematics.

<pxl-text>

A highly capable text rendering engine.

  • Attributes: text, size, font, align, baseline, weight, fontstyle.
  • Advanced Features: width triggers auto word-wrapping, letterspacing and lineheight can be animated, and reveal takes a value from 0 to 1 for a typewriter effect.
