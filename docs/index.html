Kilopixel bridges the gap between the raw performance of the HTML5 Canvas and the ease of declarative HTML. Without needing to write a single line of JavaScript, you can build complex, responsive graphics using nothing but custom HTML elements like <pxl-stage> and <pxl-circle>.

Powered by a lightning-fast evaluation engine, Kilopixel processes math expressions, element reactivity, and continuous animations natively at 60 frames per second â€” all with absolutely zero build tools required.

See it in Action

The simple HTML snippet below generates the live, continuous canvas animation underneath it. Notice how the circle's movement and color are driven purely by mathematical expressions written directly inside the element's attributes!

<!-- An autonomous, color-shifting circle gliding across the canvas -->
<pxl-stage ratio="16 / 9">
  <pxl-layer x="500" y="280">
    <pxl-grid stroke="#f1f5f9" fill="#94a3b8" major="4" labels="true" labelsize="18"></pxl-grid>
    <pxl-circle 
      x="wave(4) * 300" 
      y="0" 
      r="40 + wave(2) * 20" 
      fill="hsl(t * 100, 100, 60)" 
    ></pxl-circle>
  </pxl-layer>
</pxl-stage>

Why Kilopixel?

  • Zero Build Steps: No NPM, Webpack, or bundling required. Just drop in a single script tag and start writing.
  • Declarative Syntax: Describe your graphics visually using nested custom HTML elements.
  • Native Reactivity: Bind properties to mouse coordinates, time, or other elements using the zero-GC ref.* registry.
  • Blazing Fast: The internal engine bypasses the slow DOM entirely during the 60fps render loop.
