Introduction

Kilopixel draws 2D graphics on an HTML canvas from custom HTML elements. Shapes are written as tags such as <pxl-circle>, and any attribute can be a short expression, so a shape can move over time, follow the pointer or follow another shape.

  • One Script File: include pxl.min.js with a <script> tag. No dependencies.
  • No Build Step: no npm, no bundler, nothing to compile. Write HTML and open it in the browser.
  • No Web Server Needed: a page also works when it is opened as a local file.
  • Redrawn Only on Change: while nothing moves, Kilopixel uses no CPU time at all. When something changes, only the layers affected are redrawn, and stages scrolled out of view pause.

1. A First Example

A rect, a circle and a line. Every attribute is a plain number.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-rect x="200" y="300" w="200" h="200"
      fill="#dbeafe66" stroke="#3b82f6" strokewidth="4">
    </pxl-rect>
    <pxl-circle x="500" y="300" r="100"
      fill="#ffedd566" stroke="#f97316" strokewidth="4">
    </pxl-circle>
    <pxl-line x1="700" y1="200" x2="850" y2="400"
      stroke="#22c55e" strokewidth="4">
    </pxl-line>
  </pxl-layer>
</pxl-stage>
  • Structure: a <pxl-stage> holds a <pxl-layer>, and the layer holds the shapes.
  • Width: the stage is a 1000-width logical canvas, whatever its size on the screen, so x="500" is always the middle. The grid lines are 100 apart.
  • Position: x and y place the rect and the circle by their center; the line runs from x1, y1 to x2, y2.

2. Moving and Reacting

The same three shapes, with expressions instead of numbers. Move the pointer over the stage.

<pxl-stage id="main" ratio="5 / 3">
  <pxl-layer>
    <pxl-rect x="200" y="300" w="200" h="200"
      fill="#dbeafe66" stroke="#3b82f6" strokewidth="4"
      rotate="t * 45">
    </pxl-rect>
    <pxl-circle id="ball" x="500" y="300"
      fill="#ffedd566" stroke="#f97316" strokewidth="4"
      r="60 + wave(2) * 40">
    </pxl-circle>
    <pxl-line stroke="#22c55e" strokewidth="4"
      x1="ref.ball.x + ref.ball.r" y1="300"
      x2="ref.main.mouseX" y2="ref.main.mouseY">
    </pxl-line>
  </pxl-layer>
</pxl-stage>
  • Time: t is the time in seconds, so rotate="t * 45" turns the rect by 45° per second. wave(2) goes from 0 to 1 and back every 2 seconds.
  • References: ref.ball.r reads the circle's radius, so the line always starts at its edge.
  • Pointer: ref.main.mouseX and mouseY are the pointer's position on the stage, measured like x and y.

The Gallery shows larger examples built the same way.

3. What It Is For

Kilopixel suits graphics that are written once and then move or react on their own: diagrams, explanatory figures, interactive illustrations in documentation and teaching material, small dashboards. Scenes with thousands of independently scripted objects, 3D graphics or pixel-level image processing are a better fit for the canvas or WebGL APIs used directly.
