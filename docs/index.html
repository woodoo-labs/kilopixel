Kilopixel Framework

Welcome to the official documentation for **Kilopixel**.

Kilopixel is a declarative, reactive animation engine built specifically for HTML5 Canvas using Web Components. Instead of writing imperative ctx.beginPath() boilerplate and managing your own requestAnimationFrame loops, you describe your graphics natively in HTML.

Why Kilopixel?

  • Declarative HTML API: Draw circles, paths, and complex polygons just by writing HTML tags.
  • Built-in Math Engine: Animate properties at 60fps using integrated time drivers like wave() and glide().
  • Zero Build Tools: No bundlers, no npm, no React. Just drop in the script tag and go.
  • Insane Performance: A multi-tier Fast Path compiler ensures static elements cost absolutely zero CPU cycles to process per frame.

Live Example

This entire scene is generated without a single line of JavaScript. It is purely HTML.

<pxl-stage id="main">
  <pxl-layer>
    <pxl-circle 
      x="500" 
      y="500" 
      radius="150 + wave(2) * 20" 
      fill="linear(t*50, ['#00ffcc', '#0044ff'])" 
    />
  </pxl-layer>
</pxl-stage>
