Custom Shapes

A custom shape is a JavaScript class that extends pxl.Shape and draws with the canvas API. Loaded in a script after pxl.min.js, it works like a built-in shape: every common attribute, expressions, animation, ref.*, events and hit testing come with it.

1. A First Shape

A shape class has three parts. static defaults lists its own attributes with their default values, after the common ones of every shape. draw(ctx) draws the shape around its center; the canvas is already moved, rotated and scaled, so lengths are written as the HTML gives them: a radius of 200 draws as r="200" on any stage size. getBoundingBox() returns the box around the outline, through setBoundingBox(left, top, right, bottom): gradients span it, and hit testing checks it before the exact test.

this.applyStyle(ctx) fills and strokes the current path with the shape's fill and stroke, gradients, widths and dashes included. The last line, pxl.defineShape(), gives the class its tag.

// star.js: load it after pxl.min.js
pxl.Star = class Star extends pxl.Shape {
  static defaults = { ...pxl.Shape.defaults, points: 5, r: 50, ir: 20 };

  draw(ctx) {
    const { points, r, ir } = this.values;
    ctx.beginPath();
    for (let i = 0; i < points * 2; i++) {
      const angle = i * Math.PI / points - Math.PI / 2;
      const radius = i % 2 ? ir : r;
      ctx.lineTo(Math.cos(angle) * radius, Math.sin(angle) * radius);
    }
    ctx.closePath();
    this.applyStyle(ctx); // fill, then stroke
  }

  // It paints at most twice, so it needs the scratch canvas only for fill + stroke
  drawsMoreThanOnce() {
    return this.hasFill() && this.isStroked();
  }

  getBoundingBox() {
    const { r } = this.values;
    return this.setBoundingBox(-r, -r, r, r);
  }
};
pxl.defineShape('pxl-star', pxl.Star);

2. Attributes

Every key of static defaults is an attribute. It takes numbers, expressions and ref.* like a built-in attribute, a bare or removed attribute falls back to its default, and it is also a JavaScript property for frameworks. draw() reads the current values from this.values, the same object that other shapes read as ref.<id>: the right star below copies ref.star.points.

  • Lowercase Keys: HTML lowercases attribute names, so a key like pumpSpeed would never receive its attribute. pxl.defineShape() warns about it.
  • Built-in Names: ...pxl.Shape.defaults brings the position, transform and style attributes; without it the shape draws nothing, and pxl.defineShape() warns. A built-in name written again, such as fill: '#f97316', gets a new default and keeps its meaning: x still moves the shape.
  • Reserved Names: values, expressions, stage, handlers, constructor, update, render, prepare and paint are the engine's own names on every shape. pxl.defineShape() refuses a key with one of them and doesn't define the tag.
  • Presence Attributes: a key whose default is false or true becomes a presence attribute: written bare, as in <pxl-gauge ticks>, it is true (section 3).

Animation Goes Through Attributes

draw() gets no time. Animate a custom shape like any other, with an expression in an attribute: rotate="t * 30", or an attribute of the shape's own such as spin="t * 90" that draw() reads. The engine then knows the shape moves, redraws it in every frame and hit tests it where it is drawn.

3. Free Drawing

draw() may use any canvas call, as often as it needs. The gauge below paints a light track, a value arc in the shape's own stroke (applyStrokeState() sets color or gradient, width, caps and dashes without stroking), tick marks with the presence attribute ticks, and a label in the shape's fill. this.paint(ctx, 'fill') returns the fill as a canvas style: a color, or a gradient built in the shape's box.

By default a shape is hit where it fills and strokes. hitTest(ctx) replaces that with a hit area of its own: it adds a path and calls ctx.fill(), which tests the pointer instead of painting. The gauge is hit on its whole half disc, not only on the arcs.

// gauge.js: load it after pxl.min.js
pxl.Gauge = class Gauge extends pxl.Shape {
  static defaults = { ...pxl.Shape.defaults, value: 0, r: 100, label: '', ticks: false };

  draw(ctx) {
    const { value, r, label, ticks, strokewidth } = this.values;
    const end = Math.PI * (1 + Math.min(1, Math.max(0, value)));

    // Track: a fixed light arc under the value
    ctx.beginPath();
    ctx.arc(0, 0, r, Math.PI, 2 * Math.PI);
    ctx.lineWidth = strokewidth;
    ctx.strokeStyle = '#e2e8f0';
    ctx.stroke();

    // Value: the shape's own stroke (color or gradient, width, caps, dashes)
    ctx.beginPath();
    ctx.arc(0, 0, r, Math.PI, end);
    this.applyStrokeState(ctx);
    ctx.stroke();

    // Ticks, with the bare attribute <pxl-gauge ticks>
    if (ticks) {
      ctx.beginPath();
      for (let i = 0; i <= 10; i++) {
        const a = Math.PI * (1 + i / 10), c = Math.cos(a), s = Math.sin(a);
        const inner = r - strokewidth, outer = r - strokewidth * (i % 5 ? 1.4 : 1.8);
        ctx.moveTo(c * inner, s * inner);
        ctx.lineTo(c * outer, s * outer);
      }
      ctx.lineWidth = 3;
      ctx.setLineDash([]);
      ctx.strokeStyle = '#94a3b8';
      ctx.stroke();
    }

    // Label in the shape's fill
    ctx.fillStyle = this.paint(ctx, 'fill');
    ctx.font = `600 ${r * 0.26}px sans-serif`;
    ctx.textAlign = 'center';
    ctx.fillText(label, 0, -r * 0.12);
  }

  // The half disc, without the stroke (like the built-in shapes)
  getBoundingBox() {
    const { r } = this.values;
    return this.setBoundingBox(-r, -r, r, 0);
  }

  // The hit area: the whole half disc with the stroke, not only the painted arcs
  hitTest(ctx) {
    const b = this.getBoundingBox(), pad = this.values.strokewidth / 2;
    ctx.rect(b.left - pad, b.top - pad, b.right - b.left + 2 * pad, b.bottom - b.top + pad);
    ctx.fill();
  }
};
pxl.defineShape('pxl-gauge', pxl.Gauge);

4. Compositing

The canvas applies a shadow, blend, mask or filter to every paint call on its own. A shape that paints more than once would cast its stroke's shadow onto its own fill, or mask its fill away with its stroke. Such a shape is drawn into a scratch canvas first and goes onto the layer in one step, like an SVG group, which costs a little time.

drawsMoreThanOnce() tells the engine whether that is needed. The default is true, which is always correct. A shape that paints once can say so and is then drawn directly:

// One fill() or one stroke(): never more than once
drawsMoreThanOnce() {
  return false;
}

// applyStyle() on one path: twice only when the shape has both a fill and a stroke
drawsMoreThanOnce() {
  return this.hasFill() && this.isStroked();
}

// Several paint calls (the gauge): leave the method out

Count the paint calls (fill(), stroke(), fillText(), drawImage()), not the paths: five dots in one path filled once paint once.

5. Rules

  • Lengths as in the HTML: write radii, line widths, dash lengths and font sizes as the attributes give them. The engine scales the canvas to the stage. Only pixel access (getImageData()) works in canvas pixels; this.stage.unit is the number of CSS pixels per unit.
  • Only Values in Draw: draw() reads this.values and nothing else: no time, no DOM, no network. It runs in every frame the shape changes and in hit tests, so it should create as few objects as it can.
  • The Box Without the Stroke: getBoundingBox() covers the outline, like the box of the built-in shapes; hit testing adds half the stroke itself. Without the method, gradients collapse to a point, and pxl.defineShape() warns.
  • A Clean Canvas: the engine sets the transform, alpha, compositing and shadow before draw() and restores the canvas afterwards. A shape may change any canvas state; an error in draw() skips the shape for that frame with a warning.
  • Content Inside the Tag: text written inside <pxl-star> stays hidden once the shape's script has run.

6. TypeScript

The type definitions (Frameworks) include PxlShapeAttributes and PxlShapeElement, the attributes and properties every shape has. A custom shape's declaration extends them with its own attributes:

// star.d.ts, next to kilopixel.d.ts
export {};

declare global {
  interface PxlStarAttributes extends PxlShapeAttributes {
    points?: PxlNumber | null;
    r?: PxlNumber | null;
    ir?: PxlNumber | null;
  }
  interface PxlStarElement extends PxlShapeElement {
    get points(): number; set points(value: PxlNumber | null | undefined);
    get r(): number; set r(value: PxlNumber | null | undefined);
    get ir(): number; set ir(value: PxlNumber | null | undefined);
  }
  interface HTMLElementTagNameMap { 'pxl-star': PxlStarElement }
}

For JSX and templates, copy the line of a built-in shape from the framework's file (kilopixel-react.d.ts, …) and rename it. For React:

import type { DetailedHTMLProps, HTMLAttributes } from 'react';

declare module 'react' {
  namespace JSX {
    interface IntrinsicElements {
      'pxl-star': Omit<DetailedHTMLProps<HTMLAttributes<PxlStarElement>, PxlStarElement>,
        keyof PxlStarAttributes> & PxlStarAttributes;
    }
  }
}

7. Shape Class Reference

The table below lists what a custom shape writes, what it may override, and what it may read and call. Everything else on pxl.Shape is internal and may change. The other tabs list the attributes every shape gets.

Every Custom Shape
class … extends pxl.Shape
class
The shape, in a script loaded after pxl.min.js. pxl.Star = class Star … puts it on the pxl namespace like the built-in shapes; a plain class Star works the same.
static defaults
object
Every attribute of the shape with its default, after ...pxl.Shape.defaults. Keys in lowercase; a false or true default makes a presence attribute.
draw(ctx)
methodrequired
Draws the shape around its center, with lengths as in the HTML. Reads only this.values.
getBoundingBox()
methodrecommended
Returns the box around the outline, without the stroke: return this.setBoundingBox(left, top, right, bottom). Gradients span it; hit testing checks it first. A shape with mask, blend, filter or a shadow that fills and strokes is drawn only within this box plus hitPadding(): paint beyond them is cut.
pxl.defineShape(tag, Class)
function
Defines the tag ('pxl-star'; the pxl- prefix is a convention) and hides content written inside it. Warns once for keys with capitals, defaults without ...pxl.Shape.defaults, a missing draw() or getBoundingBox(), and a tag that is already defined. A reserved key (section 2) is an error, and the tag is not defined.
Optional Methods
hitTest(ctx)
methoddefault: what draw() paints
The hit area: add a path and call ctx.fill() or ctx.stroke(), which test the pointer instead of painting.
drawsMoreThanOnce()
methoddefault: true
Whether draw() paints more than once, which decides whether a shadow, blend, mask or filter needs the scratch canvas (section 4).
hitPadding()
methoddefault: from the stroke
How far the paint reaches beyond the box, for the box check before hit testing and for the area an isolated shape is drawn in. Override it when draw() paints outside its box.
prepare(ctx)
methoddefault: true
Runs before an isolated shape's box is read. Override it when the box is only known after measuring (as text measures its glyphs), and return false when there is nothing to draw.
Read
this.values
object
The current value of every attribute, the object that expressions read as ref.<id>; also isHovered and isPressed.
this.stage.unit
number
CSS pixels per unit of the stage, for the rare drawing in canvas pixels (getImageData()).
Call
applyStyle(ctx)
method
Fills the current path with fill (if set), then strokes it with stroke (if set), gradients and dashes included.
applyStrokeState(ctx)
method
Sets the stroke color or gradient, width, caps, joins, miter limit and dashes without stroking, for stroke() on a path of your own or strokeText().
paint(ctx, 'fill' | 'stroke')
method
The fill or stroke as a canvas style: a color as written, or a gradient built in the shape's box.
hasFill(), isStroked()
method
Whether a fill, or a stroke with a width above 0, is set.
setBoundingBox(left, top, right, bottom)
method
Writes the shape's box and returns it, without creating an object.
