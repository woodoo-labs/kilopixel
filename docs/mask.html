Mask

Use the mask attribute to perform boolean clipping operations (intersections, cutouts, and knockouts) between overlapping shapes.

Architecture Rule: Shapes Only

The mask attribute applies strictly to Shapes (like <pxl-circle> or <pxl-rect>). It is a direct alias for Canvas 2D boolean clipping operations. Because Kilopixel Layers rely on CSS DOM compositing, applying a mask to a <pxl-layer> will be ignored.

1. Boolean Operations

In Canvas graphics, clipping involves a Destination shape (what is already drawn on the canvas) and a Source shape (what is about to be drawn). By changing the mask mode on the Source shape, you dictate how the two shapes intersect.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- The Destination Shape -->
    <pxl-rect x="350" y="300" w="400" h="300" fill="darkorange"></pxl-rect>

    <!-- The Source Shape -->
    <pxl-ellipse x="650" y="300" rx="200" ry="150" fill="dodgerblue" mask="destination-in"></pxl-ellipse>
  </pxl-layer>
</pxl-stage>
