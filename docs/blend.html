Alpha & Blend

Bring your graphics to life with powerful color compositing. Effortlessly mix colors, create light effects, apply overlays, and manage transparency using just a few declarative attributes.

Learn how applying compositing attributes like alpha and blend creates different effects depending on whether they are applied to a layer or a shape.

1. Alpha (Opacity)

Kilopixel allows you to apply transparency at two different architectural levels:

  • Layer Level: When alpha is applied to a <pxl-layer>, the shapes inside are drawn normally (blocking each other opaquely). Then, the entire flattened canvas element is made translucent via the CSS opacity property.
  • Shape Level: When alpha is applied directly to a <pxl-circle>, it maps to the Canvas globalAlpha property. The shapes become translucent during the draw loop, causing them to bleed through each other where they overlap.
<pxl-stage ratio="5 / 3">
  <!-- LEFT: Alpha applied to the Layer -->
  <pxl-layer alpha="0.5">
    <pxl-circle x="180" y="300" r="140" fill="darkorange"></pxl-circle>
    <pxl-circle x="320" y="300" r="140" fill="dodgerblue"></pxl-circle>
  </pxl-layer>

  <!-- RIGHT: Alpha applied directly to Shapes -->
  <pxl-layer>
    <pxl-circle x="680" y="300" r="140" fill="darkorange" alpha="0.5"></pxl-circle>
    <pxl-circle x="820" y="300" r="140" fill="dodgerblue" alpha="0.5"></pxl-circle>
  </pxl-layer>
</pxl-stage>

2. Blend Modes

In Kilopixel, you can apply any of the 16 standard CSS/Canvas color mix modes using the blend attribute. Just like alpha transparency, the behavior depends entirely on whether you apply it to a layer or a shape:

  • Layer Level: When blend is applied to a <pxl-layer>, the browser blends the entire flattened layer against the layers and CSS backgrounds behind it.
  • Shape Level: When blend is applied to a shape (e.g., a <pxl-circle>), it strictly blends against the other shapes already drawn onto that specific layer's isolated canvas buffer, completely ignoring the background.
<!-- Base Background Layer -->
<pxl-layer>
  <pxl-rect x="0" y="0" w="1000" h="600" anchor="top-left" fill="linear(90, [0.2, '#f9a8d4', 0.5, '#fde047', 0.8, '#67e8f9'])"></pxl-rect>
</pxl-layer>

<!-- Layer Level: Blends with background -->
<pxl-layer blend="normal">
  <pxl-circle x="180" y="300" r="140" fill="darkorange"></pxl-circle>
  <pxl-circle x="320" y="300" r="140" fill="dodgerblue"></pxl-circle>
</pxl-layer>

<!-- Shape Level: Blends only with shapes on the same layer -->
<pxl-layer>
  <pxl-circle x="680" y="300" r="140" fill="darkorange"></pxl-circle>
  <pxl-circle x="820" y="300" r="140" fill="dodgerblue" blend="normal"></pxl-circle>
</pxl-layer>
