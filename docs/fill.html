Fill

The fill attribute paints the interior surface of any vector shape in Kilopixel. Because fills are powered by color, this guide also introduces Kilopixel's foundational color models — including hex codes, CSS named colors, rgb() / rgba() channels, and hsl() / hsla() color spaces. All of these can be applied to both fill and stroke attributes.

Fills, Strokes & Gradients

By default, shapes have no fill (fill="none") unless an explicit color or gradient is provided. Fills are always painted before strokes in the Canvas draw pipeline. In addition to the solid color formats covered on this page, the fill attribute also accepts dynamic shaders from the Gradients section (including linear(), radial(), and conic()).

1. Named Colors & Hex Codes

In Kilopixel, you can use any valid CSS color keyword (like dodgerblue or transparent) or hexadecimal code (like #ef4444) for the fill and stroke attributes.

In addition to standard 6-digit hex codes and 3-digit shorthand (#f00), Kilopixel fully supports 8-digit hexadecimal colors (#rrggbbaa). The final two digits represent the alpha channel (e.g. #fbbf24aa), creating translucent fills that blend with underlying shapes.

Stacking Order (Z-Index): Elements are drawn strictly in the order they appear in the HTML. The last element in the markup is drawn on top of the others.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Circle 1 (Hex Code) -->
    <pxl-circle fill="#ef4444" stroke="#991b1b" x="500" y="230" r="140" strokewidth="4"></pxl-circle>
      
    <!-- Circle 2 (Named CSS Color) -->
    <pxl-circle fill="dodgerblue" stroke="royalblue" x="420" y="370" r="140" strokewidth="4"></pxl-circle>
      
    <!-- Circle 3 (8-Digit Hex with Alpha) -->
    <pxl-circle fill="#fbbf24aa" stroke="#b45309" x="580" y="370" r="140" strokewidth="4"></pxl-circle>
  </pxl-layer>
</pxl-stage>

2. RGB & RGBA

The rgb() and rgba() formats break colors down into their core numeric channels: Red, Green, and Blue (0-255). The rgba() variant adds a fourth Alpha channel (0.0 - 1.0) to control transparency, allowing overlapping shapes to blend together.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Circle 1 (Red) -->
    <pxl-circle fill="rgba(255, 0, 0, 0.7)" x="500" y="230" r="140"></pxl-circle>
      
    <!-- Circle 2 (Green) -->
    <pxl-circle fill="rgba(0, 255, 0, 0.7)" x="420" y="370" r="140"></pxl-circle>
      
    <!-- Circle 3 (Blue) -->
    <pxl-circle fill="rgba(0, 0, 255, 0.7)" x="580" y="370" r="140"></pxl-circle>
  </pxl-layer>
</pxl-stage>

3. HSL & HSLA

The hsl() and hsla() formats use Hue (0-360), Saturation (0-100), and Lightness (0-100). HSL is especially powerful for generative graphics because you can easily animate the Hue channel over time using the t variable.

Never Use % Signs!

By sticking to pure numbers (e.g., fill="hsl(120, 100, 50)"), you can seamlessly animate colors using math and time variables. The engine handles all the CSS units behind the scenes.

Exception: If you choose to use Javascript backticks (template literals) for string interpolation (e.g., fill="`hsl(${t*90}, 100%, 50%)`"), your math and time variables are evaluated natively by JavaScript. Because this bypasses Kilopixel's formatting helpers, you must include the % signs manually so the final generated string is valid CSS.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Circle 1 (Static HSL) -->
    <pxl-circle fill="hsl(0, 100, 50)" x="500" y="230" r="140"></pxl-circle>
      
    <!-- Circle 2 (HSLA with Alpha) -->
    <pxl-circle fill="hsla(120, 100, 50, 0.7)" x="420" y="370" r="140"></pxl-circle>
      
    <!-- Circle 3 (Animated Hue) -->
    <pxl-circle fill="hsl(t * 90, 100, 50)" x="580" y="370" r="140"></pxl-circle>
  </pxl-layer>
</pxl-stage>

Controls

This circle's Hue is driven by the time variable t. Adjusting the slider changes the multiplier, affecting how fast the colors cycle.

4. Gradients

The fill attribute also accepts dynamic gradient shaders: linear(), radial(), and conic(). Gradients scale smoothly with the logical canvas and adapt geometrically when shapes are rotated or resized.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- 1. Ellipse -->
    <pxl-ellipse fill="linear(45, ['darkorange', 'gold', 'crimson'])" rx="100" ry="200" rotate="0" x="150" y="300"></pxl-ellipse>
      
    <!-- 2. Hard Split Rounded Rect -->
    <pxl-rect fill="linear(135, [0, '#3b82f6', 0.5, '#3b82f6', 0.501, '#93c5fd', 1, '#93c5fd'])" w="300" h="200" r="20" rotate="0" x="500" y="300"></pxl-rect>

    <!-- 3. Gradient Text -->
    <pxl-text fill="linear(45, ['#8b5cf6', '#ec4899', '#f59e0b'])" size="150" weight="800" rotate="0" x="850" y="300" font="Inter" text="'pxl'" align="center" baseline="middle"></pxl-text>
  </pxl-layer>
</pxl-stage>
