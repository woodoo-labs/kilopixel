Text

The text shape renders labels, titles, and paragraphs directly in canvas. It supports custom fonts, weights, automatic word-wrapping, and typewriter reveal effects.

1. Font Families

The font attribute defines the typeface family, while size scales glyphs in virtual canvas units. Kilopixel seamlessly renders both custom loaded web fonts and native system typefaces.

System Typefaces vs. Web Fonts

Standard system typefaces like sans-serif, serif, monospace, and cursive are built into the operating system and draw immediately with zero network latency. External web fonts like ‘Inter’ must be preloaded in the DOM so Canvas can access their glyphs without delayed layout shifts.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Primary Text -->
    <pxl-text x="250" y="300" text="KILOPIXEL"
      font="Inter" size="70"
      fill="#f97316" align="center" baseline="middle"></pxl-text>

    <!-- Right: Secondary Text -->
    <pxl-text x="750" y="300" text="CANVAS ENGINE"
      font="serif" size="50"
      fill="#3b82f6" align="center" baseline="middle"></pxl-text>
  </pxl-layer>
</pxl-stage>
