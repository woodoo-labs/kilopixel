Text

The text shape renders labels, titles, and paragraphs directly in canvas. It supports custom fonts, weights, automatic word-wrapping, and typewriter reveal effects.

1. Typography

The font, size, weight, and fontstyle attributes configure typographic styling. Kilopixel maps numeric weights directly to loaded web fonts and native system typefaces.

System Typefaces vs. Web Fonts

Standard system typefaces like sans-serif, serif, monospace, and cursive draw immediately with zero network latency. However, not all typefaces support the full range of numeric weights: system fallbacks typically provide only regular (400) and bold (700), automatically snapping intermediate values to the nearest available cut. External web fonts like ‘Inter’ must be preloaded in the DOM so Canvas can render all nine weights (100–900) without layout shifts.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-text x="500" y="300" text="KILOPIXEL"
      font="Inter" size="70" weight="700" fontstyle="normal"
      fill="#f97316" align="center" baseline="middle"></pxl-text>
  </pxl-layer>
</pxl-stage>

2. Alignment & Baselines

The align and baseline attributes position text relative to its (x, y) center coordinates. Kilopixel provides full control over horizontal alignment and typographic vertical baselines.

The Text Center Point

In canvas typography, (x, y) does not define a top-left bounding box corner by default. Instead, it serves as a central reference: align shifts glyphs horizontally relative to x, while baseline aligns font vertical metrics (such as the cap-height, middle, or alphabetic baseline) relative to y.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Horizontal Alignment -->
    <pxl-text x="250" y="300" text="ALIGN" font="Inter" size="48" weight="700"
      align="start" baseline="middle" fill="#f97316"></pxl-text>
    
    <!-- Right: Vertical Baseline -->
    <pxl-text x="750" y="300" text="BASELINE" font="Inter" size="48" weight="700"
      align="center" baseline="alphabetic" fill="#3b82f6"></pxl-text>
  </pxl-layer>
</pxl-stage>

3. Word Wrapping & Typesetting

The width, lineheight, and letterspacing attributes control multi-line paragraph layout and character spacing. Setting width transforms a single-line label into a wrapped paragraph box.

Automatic Word Wrapping

Unlike standard canvas text rendering which requires manual text-splitting loops, setting width on a <pxl-text> shape enables built-in word wrapping. Kilopixel automatically handles whitespace splitting and multi-line vertical layout while caching calculations for high-performance rendering.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-text x="500" y="210" font="Inter" size="32" weight="500"
      align="center" baseline="top" fill="#f97316"
      width="460"
      lineheight="1.3"
      letterspacing="0"
      text="Kilopixel brings declarative canvas graphics to life with automatic word wrapping, reactive attributes, and smooth typography."></pxl-text>
  </pxl-layer>
</pxl-stage>
