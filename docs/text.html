Text

The text shape renders labels, titles, and paragraphs directly in canvas. It supports custom fonts, weights, automatic word-wrapping, and typewriter reveal effects.

Quoting Rules & Expression Guard

Kilopixel compiles attribute values through an expression engine. To ensure text renders exactly as intended, follow these quoting guidelines:

  • Plain Words & Sentences: Standard phrases and full sentences work without inner quotes (e.g., text="Declarative Canvas" or text="Graphics made simple."). Whitespace, commas, and trailing periods are safely preserved.
  • Math Operators & Parentheses: Wrap text in single quotes if it contains arithmetic operators, parentheses, or hyphenated number ranges (e.g., text="'100 - 50'", text="'(0, 0)'", text="'Years 2024-2025'"). Without quotes, expressions with operators like 100 - 50 or 2024-2025 are computed mathematically (displaying 50 or -1), while parentheses attempt a JavaScript function call. Pure numbers and labels like text="2026" or text="Page 42" do not require quotes.
  • Reactive Expressions: When concatenating variables or using template strings, use standard JavaScript syntax (e.g., text="'Width: ' + ref.box.width" or text="`Count: ${ref.count.value}`").

1. Typography

The size, weight, fontstyle, and font attributes configure typographic styling. Kilopixel maps numeric weights directly to loaded web fonts and native system fonts.

System Fonts vs. Web Fonts

Standard system fonts like sans-serif, serif, monospace, and cursive draw immediately with zero network latency. However, not all fonts support the full range of numeric weights: system fallbacks typically provide only regular (400) and bold (700), automatically snapping intermediate values to the nearest available cut. External web fonts like ‘Inter’ must be preloaded in the DOM so Canvas can render all nine weights (100–900) without layout shifts.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-text x="500" y="300" text="KILOPIXEL"
      size="70" weight="700" fontstyle="normal" font="Inter"
      fill="#f97316" align="center" baseline="middle"></pxl-text>
  </pxl-layer>
</pxl-stage>

2. Alignment

The align and baseline attributes position text relative to its (x, y) center coordinates. The align attribute shifts text horizontally relative to x, while baseline positions vertical font metrics relative to y.

Defaults are align="start" and baseline="alphabetic", matching native HTML5 Canvas behavior. When omitted, text begins at x and rests directly on the baseline at y.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-text x="500" y="300" text="Kilopixel" font="Inter" size="70" weight="700"
      align="start" baseline="alphabetic" fill="#3b82f6"></pxl-text>
  </pxl-layer>
</pxl-stage>

3. Line Breaks

Kilopixel natively parses newline characters (\n) directly inside text strings, breaking text across multiple lines without requiring a width constraint.

The lineheight attribute controls proportional vertical line spacing, while align formats individual lines relative to the shape’s center.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-text x="500" y="300" font="Inter" weight="700" fill="#f97316"
      size="42" lineheight="1.3"
      align="center" baseline="middle"
      text="Declarative Canvas\nReactive Animation\nZero Dependencies"></pxl-text>
  </pxl-layer>
</pxl-stage>

4. Word Wrap

Setting the width attribute transforms single-line text into a self-wrapping paragraph box. Kilopixel automatically reflows words at space boundaries to fit inside the column width.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-text x="500" y="300" font="Inter" weight="500" fill="#3b82f6"
      width="500" size="32"
      lineheight="1.3" letterspacing="0"
      align="center" baseline="middle"
      text="Kilopixel brings declarative canvas graphics to life with automatic word wrapping, reactive attributes, and smooth typography."></pxl-text>
  </pxl-layer>
</pxl-stage>

5. Max Width

The maxwidth attribute enforces a strict horizontal boundary by compressing and condensing glyphs rather than wrapping words into multiple lines. This is ideal for fixed-width badges, table headers, and constrained UI labels.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-text x="500" y="300" font="Inter" fill="#f97316"
      size="48" weight="700"
      maxwidth="460" letterspacing="0"
      align="center" baseline="middle"
      text="KILOPIXEL DECLARATIVE CANVAS"></pxl-text>
  </pxl-layer>
</pxl-stage>

6. Reveal

The reveal attribute controls progressive character display using a normalized percentage from 0.0 (completely hidden) to 1.0 (fully displayed). This makes typewriter animations, narrative dialogue, and telemetry readouts effortless.

Autonomous Typing Animations

While the slider below allows manual scrubbing through characters, you can animate the reveal autonomously in declarative HTML using Kilopixel’s built-in time drivers — such as reveal="loop(4)" to repeat every 4 seconds, or reveal="clamp(loop(5) * 1.3, 0, 1)" to hold on the completed message before looping.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Single-Line Headline (Orange Scheme) -->
    <pxl-text x="50" y="150" font="monospace" fill="#f97316"
      size="50" weight="700"
      reveal="0.65" letterspacing="0"
      align="start" baseline="top"
      text="Kilopixel Engine"></pxl-text>

    <!-- Right: Multi-Line Wrapped Paragraph (Blue Scheme) -->
    <pxl-text x="550" y="150" font="Inter" fill="#3b82f6"

      align="start" baseline="top"
      text="Kilopixel compiles declarative canvas graphics into 60fps animations. Progressive character reveal makes storytelling and narrative dialogue completely effortless."></pxl-text>
  </pxl-layer>

7. Outline

Text elements can be rendered in hollow outline mode by setting fill="none" alongside stroke and strokewidth. Outlines support solid colors, custom dash patterns via linedash, and dynamic directional gradients computed across the text’s bounding box.

Static Fonts for Hollow Outlines

When creating hollow outlines with fill="none", static system fonts like sans-serif are recommended. Modern variable fonts (such as Inter) often construct glyphs using overlapping component contours for weight interpolation, which the browser’s strokeText() renders as internal seams. Static fonts provide merged vector paths for clean, hollow borders.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Lower Left: Solid Outline (Orange Scheme) -->
    <pxl-text x="240" y="420" font="sans-serif" stroke="#f97316" align="center" baseline="middle"
      size="80" weight="800"
      strokewidth="4" fill="none"
      text="SOLID"></pxl-text>

    <!-- Upper Center: Dashed Outline (Blue Scheme) -->
    <pxl-text x="500" y="160" font="sans-serif" stroke="#3b82f6" fill="none" align="center" baseline="middle"
      size="80" weight="800"
      strokewidth="2" linedash="[10, 6]"
      text="DASHED"></pxl-text>

    <!-- Lower Right: Gradient Outline (Multi-Stop Linear) -->
    <pxl-text x="760" y="420" font="sans-serif" fill="none" align="center" baseline="middle"
      size="80" weight="800"
      strokewidth="4" stroke="linear(90, ['#f97316', '#ec4899', '#3b82f6'])"
      text="GRADIENT"></pxl-text>
  </pxl-layer>
</pxl-stage>

8. Direction

The direction attribute specifies the base text reading direction (ltr, rtl, or inherit). In addition to flowing right-to-left text like Arabic and Hebrew correctly, direction determines the logical orientation of align="start" and align="end".

Logical Alignment Reversal

When direction="rtl", the meaning of logical alignment flips: align="start" anchors text to the right of x (flowing leftwards), while align="end" anchors to the left. Center alignment (align="center") remains anchored directly on x.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Upper: Latin (Left-to-Right Default) -->
    <pxl-text x="500" y="160" font="Inter" fill="#f97316" weight="700" baseline="middle"
      size="50" reveal="1"
      direction="ltr" align="start"
      text="Hello Kilopixel!"></pxl-text>

    <!-- Center: Arabic (Right-to-Left Default) -->
    <pxl-text x="500" y="300" font="Inter" fill="#3b82f6" weight="700" baseline="middle"
      size="50" reveal="1"
      direction="rtl" align="start"
      text="مرحبا بك في كيلوبيكسل"></pxl-text>

    <!-- Lower: Hebrew (Right-to-Left Default) -->
    <pxl-text x="500" y="440" font="Inter" fill="#a855f7" weight="700" baseline="middle"
      size="50" reveal="1"
      direction="rtl" align="start"
      text="שלום קילופיקסל"></pxl-text>
  </pxl-layer>
</pxl-stage>

10. Element Reference

The table below covers all attributes, runtime properties, and event handlers supported by <pxl-text>. Use the tabs to switch between text-specific features and common APIs shared across all shapes.

Content & Typography
text
string | expr default: ''
Text string or reactive JavaScript expression to render. Wrap in single quotes if the content contains arithmetic operators (+, -), parentheses, or function calls. Explicit \n characters create manual line breaks.
font
string | expr default: 'sans-serif'
Font family name. Accepts custom loaded web fonts (such as 'Inter') and standard system fonts ('sans-serif', 'serif', 'monospace', 'system-ui').
size
number >= 0 | expr default: 16
Font size in logical canvas coordinates.
weight
'normal' | 'bold' | 100–900 | expr default: 'normal'
Font weight. Supports standard numeric values (100 to 900 in steps of 100) or CSS keywords ('normal', 'bold').
fontstyle
'normal' | 'italic' | 'oblique' | expr default: 'normal'
Font style variant ('normal', 'italic', or 'oblique').
Alignment & Reading Direction
align
'start' | 'center' | 'end' | 'left' | 'right' | expr default: 'start'
Horizontal text alignment anchor relative to x. In right-to-left reading mode, 'start' anchors to the right edge and flows leftwards, while 'end' anchors to the left.
baseline
'alphabetic' | 'top' | 'middle' | 'bottom' | 'hanging' | 'ideographic' | expr default: 'alphabetic'
Vertical text alignment anchor relative to y. Use 'middle' for vertical centering inside buttons, cards, or geometric shapes.
direction
'ltr' | 'rtl' | 'inherit' | expr default: null
Base text reading direction. Setting 'rtl' activates bidirectional text layout, correctly connecting Arabic and Hebrew scripts and reversing the logical anchor orientation of align="start" and align="end".
Layout & Word Wrapping
width
number >= 0 | expr default: 0
Target container width for automatic word-wrapping in logical coordinates. Words exceeding this width wrap onto subsequent lines. Set to 0 to disable wrapping.
maxwidth
number >= 0 | expr default: 0
Maximum width passed directly to the native ctx.fillText() call. If rendered text exceeds this boundary, the browser horizontally compresses and squashes glyphs to fit.
lineheight
number >= 0 | expr default: 1.2
Vertical line spacing multiplier for multi-line text (both explicit \n newlines and auto-wrapped lines). Multiplied by size to compute line spacing advance.
letterspacing
number | expr default: 0
Additional horizontal spacing between consecutive characters in logical coordinates. Positive values expand tracking; negative values condense tracking.
Animation & Effects
reveal
number (0.0–1.0) | expr default: null
Typewriter reveal effect. A normalized ratio from 0 (completely hidden) to 1 (fully revealed). Progressively uncovers characters in reading order across lines with high-performance fast-path rendering.
