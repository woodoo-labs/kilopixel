Stroke

Every vector shape in Kilopixel supports responsive, customizable stroke rendering. Learn how to control line width, apply solid or gradient strokes, configure line caps and joins, and create animated dashed lines — all rendered crisply across any screen resolution.

Unitless Logical Width

Stroke attributes like strokewidth, linedash, and dashoffset operate directly in Kilopixel's 1000-width logical canvas. A strokewidth="4" is always exactly 0.4% of the stage width, automatically scaling to physical device pixels with subpixel precision without blurring.

1. Stroke Color & Width

You can outline any Kilopixel shape using the stroke and strokewidth attributes:

  • Stroke Color (stroke): Accepts hexadecimal codes (#f97316), CSS color keywords (darkorange), functional color models (rgb(), rgba(), hsl(), hsla()), or dynamic gradient shaders (linear(), radial(), conic()). If omitted or set to none or transparent, no stroke is drawn.
  • Stroke Width (strokewidth): Sets the thickness of the stroke in unitless logical canvas coordinates. Defaults to 1. Setting strokewidth="0" disables stroke rendering.
<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Circle with configurable stroke -->
    <pxl-circle stroke="#f97316" strokewidth="8" r="140" x="300" y="300" fill="#ffedd566"></pxl-circle>

    <!-- Rounded rectangle with gradient stroke -->
    <pxl-rect stroke="#3b82f6" strokewidth="8" r="36" x="700" y="300" w="260" h="260" fill="#dbeafe66"></pxl-rect>
  </pxl-layer>
</pxl-stage>

Controls

2. Line Caps & Joins

Kilopixel provides precise control over how open stroke endpoints terminate and how corners connect:

  • Line Cap (linecap): Controls the ending shape of open paths (such as <pxl-line> and open <pxl-polyline>). Accepts butt (default, flush cut precisely at the coordinate endpoints), round (semicircular cap extending past the endpoints by half the stroke width), or square (rectangular box extending past the endpoints by half the stroke width).
  • Line Join (linejoin): Controls the shape of corners where two stroke segments meet. Accepts miter (default, sharp corner point), round (circular curved corner), or bevel (flat diagonal cut).
  • Miter Limit (miterlimit): Sets the maximum allowable ratio between the miter length and the stroke width. When acute angles make the miter point excessively long, Kilopixel automatically clips it to a bevel.

The Miter Limit Threshold

When two lines meet at an acute angle, extending their outer edges can create an excessively long, spiky point. The miterlimit attribute defines the maximum ratio between the miter length and the stroke width (defaulting to 10). If the corner angle is sharper than this threshold, the engine automatically clips the corner into a bevel.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- 1. Open line demonstrating Line Cap -->
    <pxl-line linecap="butt" strokewidth="40" x1="120" y1="300" x2="420" y2="300" stroke="#f97316"></pxl-line>

    <!-- 2. Polyline corner demonstrating Line Join & Miter Limit -->
    <pxl-polyline linejoin="miter" miterlimit="3" strokewidth="40" points="640,420; 760,160; 880,420" stroke="#3b82f6" fill="none"></pxl-polyline>
  </pxl-layer>
</pxl-stage>
