Stroke

Every vector shape in Kilopixel supports responsive, customizable stroke rendering. Learn how to control line width, apply solid or gradient strokes, configure line caps and joins, and create animated dashed lines — all rendered crisply across any screen resolution.

Unitless Logical Width

Stroke attributes like strokewidth, linedash, and dashoffset operate directly in Kilopixel's 1000-width logical canvas. A strokewidth="4" is always exactly 0.4% of the stage width, automatically scaling to physical device pixels with subpixel precision without blurring.

1. Stroke Width & Color

You can outline any Kilopixel shape using the stroke and strokewidth attributes:

  • Stroke Paint (stroke): Accepts hexadecimal codes (#f97316), CSS color keywords (darkorange), functional color models (rgb(), rgba(), hsl(), hsla()), or dynamic gradient descriptors (linear(), radial(), conic()). If omitted or set to none or transparent, no stroke is drawn.
  • Stroke Width (strokewidth): Sets the thickness of the stroke in unitless logical canvas coordinates. Defaults to 1. Setting strokewidth="0" disables stroke rendering.
<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Circle with configurable stroke -->
    <pxl-circle x="320" y="300" r="140" fill="#ffedd566"
      stroke="#f97316"
      strokewidth="8">
    </pxl-circle>

    <!-- Rounded rectangle with gradient stroke -->
    <pxl-rect x="680" y="300" w="260" h="260" r="36" fill="#dbeafe66"
      stroke="#3b82f6"
      strokewidth="8">
    </pxl-rect>
  </pxl-layer>
</pxl-stage>
