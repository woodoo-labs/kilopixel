Stroke

Every vector shape in Kilopixel supports responsive, customizable stroke rendering. Learn how to control line width, apply solid or gradient strokes, configure line caps and joins, and create animated dashed lines — all rendered crisply across any screen resolution.

Unitless Logical Width

Stroke attributes like strokewidth, linedash, and dashoffset operate directly in Kilopixel's 1000-width logical canvas. A strokewidth="4" is always exactly 0.4% of the stage width, automatically scaling to physical device pixels with subpixel precision without blurring.

1. Stroke Color & Width

You can outline any Kilopixel shape using the stroke and strokewidth attributes:

  • Stroke Color: The stroke attribute accepts any valid CSS color (hex, RGB, HSL, or named colors) as well as gradient shaders. If omitted or set to none, no stroke is drawn.
  • Stroke Width: The strokewidth attribute sets the outline thickness in logical canvas coordinates (defaults to 1). Setting it to 0 disables stroke rendering.
<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Circle with configurable stroke -->
    <pxl-circle stroke="#f97316" strokewidth="40" r="150" x="300" y="300" fill="#ffedd566"></pxl-circle>

    <!-- Rounded rectangle with gradient stroke -->
    <pxl-rect stroke="#3b82f6" strokewidth="8" r="50" x="700" y="300" w="300" h="300" fill="#dbeafe66"></pxl-rect>
  </pxl-layer>
</pxl-stage>

2. Line Caps

The linecap attribute controls the ending shape of open paths—including <pxl-line>, open <pxl-polyline>, and open circular arcs (<pxl-circle> with sweep or start/end). Kilopixel supports three standard cap styles:

  • Butt Cap: The default butt style cuts the stroke flush exactly at the path coordinates. No extra pixels extend beyond the endpoints.
  • Round Cap: The round style adds a semicircular cap extending past each endpoint by half the stroke width (radius = strokewidth / 2).
  • Square Cap: The square style adds a rectangular cap extending past each endpoint by half the stroke width.

Open Paths vs. Closed Shapes

linecap only affects paths with open endpoints. Closed shapes (such as <pxl-rect>, full 360° circles, or <pxl-circle pie="true">) close their subpaths automatically, so line caps are not rendered on them.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- 1. Straight Line -->
    <pxl-line linecap="butt" strokewidth="40" x1="150" y1="300" x2="450" y2="300" stroke="#f97316"></pxl-line>

    <!-- 2. Circular Arc -->
    <pxl-circle linecap="butt" strokewidth="40" r="150" start="135" sweep="270" x="700" y="300" stroke="#3b82f6" fill="none"></pxl-circle>
  </pxl-layer>
</pxl-stage>

3. Line Joins

The linejoin attribute determines how two connected stroke segments meet at a corner or vertex. Kilopixel supports three standard corner join styles:

  • Miter Join: The default miter style extends the outer edges of the stroke segments until they intersect in a sharp point.
  • Round Join: The round style rounds off the corner with a circular curve having a radius equal to half the stroke width.
  • Bevel Join: The bevel style slices off the outer corner with a flat diagonal edge between the outer endpoints of the two segments.

Open vs. Closed Corner Joins

Line joins apply to every vertex where two segments meet—including intermediate vertices of open <pxl-polyline> shapes, as well as the closing joint of closed shapes like <pxl-polyline closed="true"> and <pxl-rect>.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- 1. Open Chevron Corner -->
    <pxl-polyline linejoin="miter" strokewidth="40" points="150,450; 300,150; 450,450" stroke="#f97316" fill="none"></pxl-polyline>

    <!-- 2. Closed Polygon Corner -->
    <pxl-polyline linejoin="miter" strokewidth="40" points="550,450; 700,150; 850,450" closed="true" stroke="#3b82f6" fill="#dbeafe66"></pxl-polyline>
  </pxl-layer>
</pxl-stage>
