Rectangle

The primary orthogonal primitive in Kilopixel, <pxl-rect> renders sharp boxes, rounded cards, stadium pill buttons, and responsive layouts — with built-in support for 9-position anchor pinning and independent per-corner radii.

1. Dimensions

A rectangle's size is determined by its width (w) and height (h). By default, the shape is centered directly over its x and y coordinates.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Square -->
    <pxl-rect x="300" y="300" w="240" h="240" strokewidth="4" fill="#ffedd566" stroke="#f97316"></pxl-rect>

    <!-- Right: Rectangle -->
    <pxl-rect x="700" y="300" w="360" h="200" strokewidth="4" fill="#dbeafe66" stroke="#3b82f6"></pxl-rect>
  </pxl-layer>
</pxl-stage>

2. Corner Radius

The universal corner radius (r) smooths all four corners simultaneously. When r="0", the rectangle has crisp 90° corners. Increasing r softens the corners into rounded cards, and setting it to half of the shortest edge or higher creates a stadium pill or circular disc.

Automatic Radius Clamping

The canvas engine automatically clamps the effective corner radius to half of the shortest side (min(w, h) / 2). Setting r="100" on a rectangle with a height of 120 will safely clamp the radius to 60, creating a seamless pill shape without distortion.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Card -->
    <pxl-rect x="300" y="300" w="260" h="300" strokewidth="4" r="30" fill="#ffedd566" stroke="#f97316"></pxl-rect>

    <!-- Right: Pill -->
    <pxl-rect x="700" y="300" w="360" h="160" strokewidth="4" r="80" fill="#dbeafe66" stroke="#3b82f6"></pxl-rect>
  </pxl-layer>
</pxl-stage>

3. Per-Corner Radii

You can independently customize each corner of a rectangle using r1 through r4, numbered clockwise starting from the top-left corner. This allows you to construct asymmetric shapes such as tabs, badges, speech bubbles, and organic motifs.

Clockwise Ordering & Fallbacks

Corners are mapped in clockwise sequence: r1 (top-left), r2 (top-right), r3 (bottom-right), and r4 (bottom-left). Any corner without an explicit override automatically inherits the base r radius (which defaults to 0). For example, setting r="15" and r1="60" rounds three corners by 15, while giving the top-left corner an amplified curve of 60.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Tab -->
    <pxl-rect x="300" y="300" w="260" h="220" strokewidth="4"
      r1="50" r2="50" r3="0" r4="0"
      fill="#ffedd566" stroke="#f97316"></pxl-rect>

    <!-- Right: Leaf -->
    <pxl-rect x="700" y="300" w="260" h="260" strokewidth="4"
      r1="0" r2="130" r3="0" r4="130"
      fill="#dbeafe66" stroke="#3b82f6"></pxl-rect>
  </pxl-layer>
</pxl-stage>

4. Anchor

By default, rectangles position their geometric center at (x, y). The anchor attribute redefines which point of the rectangle aligns with (x, y), which also dictates the pivot point for rotations and scaling.

Default Center Alignment

Unlike the native HTML5 Canvas API or SVG where rectangles always originate from their top-left corner, Kilopixel defaults to anchor="center". To align a rectangle like standard canvas or SVG shapes, set anchor="top-left".

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-rect x="500" y="300"
      w="320" h="200"
      anchor="center" r="20"
      fill="#ffedd566" stroke="#f97316" strokewidth="4"></pxl-rect>
  </pxl-layer>
</pxl-stage>

5. Transforms

The anchor attribute directly establishes the local transform origin for rotation (rotate) and scaling (scale, scalex, scaley). When a shape transforms, it pivots around the exact reference point designated by its anchor.

Hinges vs. Symmetrical Spins

A rectangle with anchor="center" rotates symmetrically in place. Setting anchor="top-left" turns that corner into a stationary hinge, swinging the entire rectangle through an orbital trajectory without having to calculate trigonometric offsets.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Center Spin -->
    <pxl-rect x="300" y="300" w="220" h="150" fill="#ffedd566" stroke="#f97316" strokewidth="4"
      anchor="center"
      rotate="30" scalex="1.0" scaley="1.0"></pxl-rect>

    <!-- Right: Corner Hinge -->
    <pxl-rect x="700" y="300" w="220" h="150" fill="#dbeafe66" stroke="#3b82f6" strokewidth="4"
      anchor="top-left"
      rotate="30" scalex="1.0" scaley="1.0"></pxl-rect>
  </pxl-layer>
</pxl-stage>

10. Element Reference

The table below covers all attributes, runtime properties, and event handlers supported by <pxl-rect>. Use the tabs to switch between rectangle-specific features and common APIs shared across all shapes.

Dimensions & Anchor
w
number >= 0 | expr default: 0
Width of the rectangle.
h
number >= 0 | expr default: 0
Height of the rectangle.
anchor
string | expr default: 'center'
Position anchor relative to the rectangle's bounding box that aligns with (x, y) and serves as the pivot for rotations and scaling. Accepts 9 positions: 'top-left', 'top', 'top-right', 'left', 'center', 'right', 'bottom-left', 'bottom', 'bottom-right'.
Corner Radii
r
number >= 0 | expr default: null
Universal corner radius applied to all four corners. When set, corners are rounded with circular arcs. Defaults to null (sharp corners).
r1
number >= 0 | expr default: null
Top-left corner radius override. Falls back to r (or 0) if null.
r2
number >= 0 | expr default: null
Top-right corner radius override. Falls back to r (or 0) if null.
r3
number >= 0 | expr default: null
Bottom-right corner radius override. Falls back to r (or 0) if null.
r4
number >= 0 | expr default: null
Bottom-left corner radius override. Falls back to r (or 0) if null.
