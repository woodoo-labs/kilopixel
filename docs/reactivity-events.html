Reactivity and Events

Kilopixel is fully reactive. Changes to elements, mouse movements, or custom variables instantly update the scene.

The ref. Registry

The framework completely avoids expensive DOM traversal. All elements with an id attribute are automatically registered in an O(1) zero-GC registry.

You can reference the properties of any element by prefixing it with ref..

The Golden Rule: If you want to reference something in math, give it an HTML id.

<pxl-stage id="main">
  <pxl-layer>
    <!-- The 'leader' circle tracks the mouse -->
    <pxl-circle id="leader" x="ref.main.mouseX" y="ref.main.mouseY" radius="50" />
    
    <!-- The 'follower' tracks the leader! -->
    <pxl-circle x="ref.leader.x" y="ref.leader.y" radius="20" fill="red" />
  </pxl-layer>
</pxl-stage>

The engine tracks these dependencies automatically. Re-evaluations only happen when the referenced element actually updates.

Default Stage Properties

If your stage is <pxl-stage id="main">, you automatically have access to:

  • ref.main.mouseX / ref.main.mouseY
  • ref.main.isHovered
  • ref.main.width (always 1000)
  • ref.main.height (dynamic based on aspect ratio)
  • ref.main.fps (current frames per second)

<pxl-var> User Variables

You can declare custom reactive variables in HTML:

<pxl-var id="speed" value="50"></pxl-var>

<pxl-circle rotate="t * ref.speed.value" />

Dual-Architecture Interaction Engine

Kilopixel uses a seamless dual-architecture for handling pointer inputs across Mouse and Touch devices natively.

1. Declarative States (For Styling)

These are continuous boolean properties automatically updated by the framework. They are ideal for hover effects and visual feedback inside math expressions.

  • isHovered: True while the pointer is over the shape.
  • isPressed: True while the pointer is held down on the shape.
<pxl-rect 
  id="btn" 
  fill="ref.btn.isPressed ? 'red' : (ref.btn.isHovered ? 'blue' : 'gray')" 
  scale="ref.btn.isPressed ? 0.9 : 1"
/>

2. Imperative Events (For Logic)

Instantaneous actions that evaluate natively as JavaScript blocks. These are used to mutate variables, execute logic, or trigger state changes.

  • Available events: onenter, onleave, ondown, onup, onclick, onmove.
  • (Note: Do not use onhover, use onenter instead).
<!-- Clicking the button updates the variable -->
<pxl-rect 
  onclick="ref.speed.set('value', ref.speed.value + 10)" 
/>
