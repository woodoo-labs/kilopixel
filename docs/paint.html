Fill & Stroke

Shapes in Kilopixel are styled using two paint channels: fill for the interior and stroke for the outline. Both attributes accept solid colors and dynamic gradients.

1. The Two Paint Channels

A shape's appearance is defined by two complementary attributes:

  • Interior: The fill attribute paints the inside of the shape. Defaults to none (transparent).
  • Outline: The stroke attribute draws the border around the shape. Defaults to none.
  • Outline Width: The strokewidth attribute controls the border thickness in responsive logical canvas units (defaults to 1).

Stacking Order

Fills are always drawn before strokes in the Canvas render pipeline. This guarantees that your stroke outlines render sharply on top of the interior fill without being occluded.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-circle 
      x="500" y="300" r="160" 
      fill="#fb923c" 
      stroke="#0284c7" 
      strokewidth="20">
    </pxl-circle>
  </pxl-layer>
</pxl-stage>

2. Values & Shaders

Both the fill and stroke attributes accept two categories of visual values:

  • Solid Colors: Named CSS colors, hex codes (including 8-digit alpha hex), rgb() / rgba(), and hsl() / hsla() color spaces. See the Color guide for full details.
  • Gradient Shaders: Smooth color transitions calculated mathematically at draw time:
    • Linear Gradient — Directional angles and vector lines.
    • Radial Gradient — Concentric circles, focal offsets, and 3D cones.
    • Conic Gradient — Sweeping 360° color wheels.
  • Line Styles: Fine-tune the contour using strokewidth, linecap, linejoin, and linedash. See the Line Style guide.
