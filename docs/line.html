Line

The line shape draws straight lines between two points. It supports customizable line caps, dashed stroke patterns, and start and end arrowheads.

1. Start & End Points

A line connects a start point (x1, y1) to an end point (x2, y2).

Stroke Required for Visibility

Because lines have zero interior area, the fill attribute has no visual effect. A line requires a defined stroke color (and a strokewidth greater than 0) to be visible.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Horizontal Line -->
    <pxl-line stroke="#f97316" strokewidth="20"
      x1="150" y1="300"
      x2="450" y2="300">
    </pxl-line>

    <!-- Right: Diagonal Line -->
    <pxl-line stroke="#3b82f6" strokewidth="4"
      x1="550" y1="450"
      x2="850" y2="150">
    </pxl-line>
  </pxl-layer>
</pxl-stage>

2. Line Styles

Because lines have no interior area, their visual appearance is defined entirely by their stroke styling — including thickness (strokewidth), end caps (linecap), dash patterns (linedash), and gradient colors (stroke).

Line Styling

For dedicated interactive guides to each stroke feature, see Stroke & Width, Caps & Joins, and Dashes in the Line Styles section.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Dashed Line with Round Caps -->
    <pxl-line x1="150" y1="300" x2="450" y2="300" stroke="#f97316"
      linedash="20" strokewidth="6"
      linecap="round">
    </pxl-line>

    <!-- Right: Gradient Stroke Line -->
    <pxl-line x1="550" y1="300" x2="850" y2="300"
      stroke="linear(0, ['#3b82f6', '#ec4899'])"
      strokewidth="30" linecap="round">
    </pxl-line>
  </pxl-layer>
</pxl-stage>

3. Arrowheads

Straight lines can be turned into directional arrows by adding arrowheads to either endpoint. Kilopixel supports solid triangles (arrowstyle="filled") and open chevrons (arrowstyle="line"), with automatic proportional scaling ('auto') or custom numeric sizing.

Deep Dive: Arrowhead Styling & Mechanics

For complete documentation on automatic scaling formulas ('auto' = strokewidth × 3.6), tangent calculations, dash interactions, and cross-shape comparisons, see the dedicated Arrowheads guide in Line Styles.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Auto-Sized Arrowheads -->
    <pxl-line x1="150" y1="300" x2="450" y2="300" stroke="#f97316"
      arrowstart="auto" arrowend="auto"
      strokewidth="10" arrowstyle="filled">
    </pxl-line>

    <!-- Right: Custom-Sized Arrowheads -->
    <pxl-line x1="550" y1="300" x2="850" y2="300" stroke="#3b82f6"
      arrowstart="0" arrowend="35"
      strokewidth="6" arrowstyle="line">
    </pxl-line>
  </pxl-layer>
</pxl-stage>

4. Transforms

In Kilopixel, every shape lives inside a parent layer. Understanding how a line is positioned and transformed requires seeing both the layer coordinate space and the line's local space in action.

<pxl-stage ratio="5 / 3">
  <pxl-layer x="0" y="0" rotate="0">
    <pxl-line stroke="#f97316" strokewidth="4"
      x="500" y="300"
      x1="-300" y1="0"
      x2="300" y2="0"
      rotate="0">
    </pxl-line>
  </pxl-layer>
</pxl-stage>
