Line

The line shape draws straight lines between two points. It supports customizable line caps, dashed stroke patterns, and start and end arrowheads.

Line Styling

For stroke colors, caps, and dashes, see Stroke & Width, Caps & Joins, and Dashes in the Line Styles section.

1. Start & End Points

A line connects a start point (x1, y1) to an end point (x2, y2).

Stroke Required for Visibility

Because lines have zero interior area, the fill attribute has no visual effect. A line requires a defined stroke color (and a strokewidth greater than 0) to be visible.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Horizontal Line -->
    <pxl-line x1="150" y1="300" 
              x2="450" y2="300" 
              stroke="#f97316" strokewidth="20"></pxl-line>

    <!-- Right: Diagonal Line -->
    <pxl-line x1="550" y1="450" 
              x2="850" y2="150" 
              stroke="#3b82f6" strokewidth="4"></pxl-line>
  </pxl-layer>
</pxl-stage>

Controls

2. Arrowheads

Straight lines can be turned into directional arrows by adding arrowheads to either endpoint:

  • Two Styles: Solid triangles (arrowstyle="filled") or open chevrons (arrowstyle="line").
  • Independent Sizing: Separate size controls for the start (arrowstart) and end (arrowend) arrowheads.
  • Automatic Sizing: Sizing defaults to 'auto' (scaling proportionally to strokewidth × 3.6), with support for explicit numbers.
<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Filled Arrowhead -->
    <pxl-line x1="150" y1="300" x2="450" y2="300" stroke="#f97316"
      strokewidth="20" arrowstyle="filled"
      arrowstart="auto" arrowend="auto"></pxl-line>

    <!-- Right: Line Arrowheads -->
    <pxl-line x1="550" y1="300" x2="850" y2="300" stroke="#3b82f6"
      strokewidth="6" arrowstyle="line"
      arrowstart="60" arrowend="25"></pxl-line>
  </pxl-layer>
</pxl-stage>
