Line

The line shape draws straight lines between two points. It supports customizable line caps, dashed stroke patterns, and start and end arrowheads.

1. Start & End Points

A line connects a start point (x1, y1) to an end point (x2, y2).

Stroke Required for Visibility

Because lines have zero interior area, the fill attribute has no visual effect. A line requires a defined stroke color (and a strokewidth greater than 0) to be visible.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Horizontal Line -->
    <pxl-line stroke="#f97316" strokewidth="20"
      x1="150" y1="300"
      x2="450" y2="300">
    </pxl-line>

    <!-- Right: Diagonal Line -->
    <pxl-line stroke="#3b82f6" strokewidth="4"
      x1="550" y1="450"
      x2="850" y2="150">
    </pxl-line>
  </pxl-layer>
</pxl-stage>

2. Line Styles

Because lines have no interior area, their visual appearance is defined entirely by their stroke styling — including thickness (strokewidth), end caps (linecap), dash patterns (linedash), and gradient colors (stroke).

Line Styling

For dedicated interactive guides to each stroke feature, see Stroke & Width, Caps & Joins, and Dashes in the Line Styles section.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Dashed Line with Round Caps -->
    <pxl-line x1="150" y1="300" x2="450" y2="300" stroke="#f97316"
      linedash="20" strokewidth="6"
      linecap="round">
    </pxl-line>

    <!-- Right: Gradient Stroke Line -->
    <pxl-line x1="550" y1="300" x2="850" y2="300"
      stroke="linear(0, ['#3b82f6', '#ec4899'])"
      strokewidth="30" linecap="round">
    </pxl-line>
  </pxl-layer>
</pxl-stage>

3. Arrowheads

Straight lines can be turned into directional arrows by adding arrowheads to either endpoint. Kilopixel supports filled triangles (arrowstyle="filled") and open chevrons (arrowstyle="line"), with automatic proportional scaling ('auto') or custom numeric sizing.

More on Arrowheads

For sizing, styles, and further examples, see the dedicated Arrowheads guide.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Auto-Sized Arrowheads -->
    <pxl-line x1="150" y1="300" x2="450" y2="300" stroke="#f97316"
      arrowstart="auto" arrowend="auto"
      strokewidth="10" arrowstyle="filled">
    </pxl-line>

    <!-- Right: Custom-Sized Arrowheads -->
    <pxl-line x1="550" y1="300" x2="850" y2="300" stroke="#3b82f6"
      arrowstart="0" arrowend="35"
      strokewidth="6" arrowstyle="line">
    </pxl-line>
  </pxl-layer>
</pxl-stage>

4. Center Point

A line rotates around its center point (x, y). Because the start and end points are placed relative to the center point, its position along the line decides how the line turns: around its start point, its middle, or its end point.

Relative End Points

The start and end points (x1, y1, x2, y2) are measured from the center point (x, y), which is also the point the line rotates (rotate) and scales (zoom, scalex, scaley) around. Without x and y, the center point is the layer origin (0, 0) — usually the top-left corner of the stage.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Top: Center at Start Point -->
    <pxl-line x2="400" stroke="#f97316" strokewidth="4"
      x="300" y="150" rotate="0">
    </pxl-line>

    <!-- Middle: Center at Midpoint -->
    <pxl-line x1="-200" x2="200" stroke="#3b82f6" strokewidth="4"
      x="500" y="300" rotate="0">
    </pxl-line>

    <!-- Bottom: Center at End Point -->
    <pxl-line x1="-400" stroke="#22c55e" strokewidth="4"
      x="700" y="450" rotate="0">
    </pxl-line>
  </pxl-layer>
</pxl-stage>

5. Element Reference

The table below covers all attributes, runtime properties, and event handlers supported by <pxl-line>. Use the tabs to switch between line-specific features and common APIs shared across all shapes.

Line Geometry Attributes
x1 / y1
number | expr default: 0
Start point of the line, measured from the center point (x, y).
x2 / y2
number | expr default: 0
End point of the line, measured from the center point (x, y). The line rotates and scales around the center point.
Arrowhead Decorations
arrowstart
'auto' | number default: 0
Draws an arrowhead at the start point (x1, y1). Use 'auto' to automatically scale the size to strokewidth * 3.6. Arrowheads require a stroke.
arrowend
'auto' | number default: 0
Draws an arrowhead at the end point (x2, y2). Use 'auto' to automatically scale the size to strokewidth * 3.6.
arrowstyle
'filled' | 'line' default: 'filled'
Visual appearance of the arrowheads ('filled' solid triangle vs. 'line' open v-shape).
