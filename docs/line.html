Line

The line shape draws straight lines between two points. It supports customizable line caps, dashed stroke patterns, and start and end arrowheads.

Line Styling Topics

Looking for stroke colors, line caps, or dash patterns? Check out Stroke & Width, Caps & Joins, and Dashes for dedicated guides on generic stroke styling.

1. Start & End Points

A line connects a start point (x1, y1) to an end point (x2, y2). You can position both points anywhere on the 1000-width stage by setting x1 and y1 for the start, and x2 and y2 for the end.

Stroke Required for Visibility

Because lines have zero interior area, the fill attribute has no visual effect. A line requires a defined stroke color (and a strokewidth greater than 0) to be visible.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Horizontal Line -->
    <pxl-line x1="150" y1="300" 
              x2="450" y2="300" 
              stroke="#f97316" strokewidth="4"></pxl-line>

    <!-- Right: Diagonal Line -->
    <pxl-line x1="600" y1="420" 
              x2="850" y2="180" 
              stroke="#3b82f6" strokewidth="4"></pxl-line>
  </pxl-layer>
</pxl-stage>

Controls

2. Arrowheads

Adding arrowheads turns a straight line into a directional vector or diagram arrow. Kilopixel provides independent controls for arrowheads at the start (arrowstart) and end (arrowend) of a line, with two visual styles (arrowstyle): solid 'filled' triangles or open 'line' chevrons.

Automatic Sizing with 'auto'

Setting arrowstart="auto" or arrowend="auto" automatically scales the arrowhead proportionally to the stroke thickness (strokewidth × 3.6). You can also specify an explicit number to scale the arrowhead independently of the stroke.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Filled Arrowhead -->
    <pxl-line x1="150" y1="300" x2="450" y2="300"
      strokewidth="6" stroke="#f97316"
      arrowstyle="filled"
      arrowstart="0" 
      arrowend="30"></pxl-line>

    <!-- Right: Line Arrowheads -->
    <pxl-line x1="600" y1="300" x2="900" y2="300"
      strokewidth="6" stroke="#3b82f6"
      arrowstyle="line"
      arrowstart="25" 
      arrowend="25"></pxl-line>
  </pxl-layer>
</pxl-stage>
