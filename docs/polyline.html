Polyline

The polyline shape draws connected paths through a list of points. It supports smooth curves, closed and filled outlines, coordinates that animate one by one, and start and end arrowheads.

1. Points

A polyline connects a list of points with straight segments. Points are separated by semicolons and the x and y values of a point by a comma, so points="50,300; 150,200; 350,400; 450,300" draws a zig-zag through (50, 300), (150, 200), (350, 400) and (450, 300).

Every x and every y value is its own expression. A value can use math like min(a, b), follow a variable like ref.* or animate on its own like sin(t), while all other points stay where they are: points="50,300; 150,200 + sin(t) * 100; 350,400; 450,300" moves only the peak up and down.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Zig-Zag -->
    <pxl-polyline stroke="#f97316" strokewidth="8"
      points="50,300; 150,200; 350,400; 450,300">
    </pxl-polyline>

    <!-- Right: Bow Tie -->
    <pxl-polyline stroke="#3b82f6" strokewidth="4"
      points="850,200; 950,300; 850,400; 650,200;
              550,300; 650,400; 850,200">
    </pxl-polyline>
  </pxl-layer>
</pxl-stage>

2. Closed & Filled

A polyline stops at its last point. closed adds the segment from the last point back to the first one, so the outline wraps around. There is no need to repeat the first point: the bow tie below uses six points and closed instead of ending on 850,200 again.

fill paints the area inside the outline. The fill always reaches back to the first point, even on an open polyline: closed only decides whether that last edge is stroked.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Zig-Zag -->
    <pxl-polyline stroke="#f97316" strokewidth="8" fill="#ffedd566"
      points="50,300; 150,200; 350,400; 450,300"
      closed="false">
    </pxl-polyline>

    <!-- Right: Bow Tie -->
    <pxl-polyline stroke="#3b82f6" strokewidth="4" fill="#dbeafe66"
      points="850,200; 950,300; 850,400; 650,200; 550,300; 650,400"
      closed="true">
    </pxl-polyline>
  </pxl-layer>
</pxl-stage>

3. Smooth

smooth turns the straight segments into a curve that still passes through every point. A bare smooth is the same as smooth="1".

The number sets the tension: 0 keeps the segments straight, 1 is the default and higher values bend the curve further out. At 1 the zig-zag becomes a wave, at about 1.7 the bow tie becomes an infinity sign. The bow tie is closed, so the curve also runs smoothly through its first point.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Zig-Zag -->
    <pxl-polyline stroke="#f97316" strokewidth="4"
      points="50,300; 150,200; 350,400; 450,300"
      smooth="1">
    </pxl-polyline>

    <!-- Right: Bow Tie -->
    <pxl-polyline stroke="#3b82f6" strokewidth="4"
      points="850,200; 950,300; 850,400; 650,200;
              550,300; 650,400"
      smooth="1" closed="true">
    </pxl-polyline>
  </pxl-layer>
</pxl-stage>

4. Sharp Corners

A smooth polyline bends at every point. To keep a sharp corner, repeat that point, like 250,200; 250,200: the curve arrives and leaves the point without rounding it, while all other points stay smooth. The heart repeats the dip between its lobes. It also ends on its first point 250,450: a closed path connects its end back to its start, so the same start and end point counts as a repeated point, and the bottom tip stays sharp.

The closed teardrop writes its top point 750,150 once, so its tip is round. Repeat it at the end and the tip turns sharp. Point lists from other formats often end on their first point: for a smooth loop, drop the last point and use closed.

Round or Sharp?

With smooth, the points decide where the corners are: the two ends of an open polyline are sharp, every other point is round, and a point written twice is sharp. closed removes the ends, so a closed polyline is round all the way around unless it repeats a point.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Heart -->
    <pxl-polyline stroke="#f97316" strokewidth="4" fill="#ffedd566"
      points="250,450; 50,250; 150,150; 250,200; 250,200;
              350,150; 450,250; 250,450"
      smooth="1.6" closed="true">
    </pxl-polyline>

    <!-- Right: Teardrop -->
    <pxl-polyline stroke="#3b82f6" strokewidth="4" fill="#dbeafe66"
      points="750,150; 850,300; 800,400; 700,400;
              650,300; 750,150"
      smooth="1.3" closed="true">
    </pxl-polyline>
  </pxl-layer>
</pxl-stage>

5. Relative Mode

With mode="relative", every point after the first is an offset from the point before it: 100,0 means 100 to the right, 0,-100 means 100 up. Only the first point is a position on the stage.

Because each point builds on the one before, changing one offset moves every point after it: in the house, the wall height 0,-150 lifts the whole roof, and the left wall, the closing segment, follows on its own. Repeated steps can share one value: every step of the staircase uses ref.stepWidth.value and ref.stepHeight.value, so two variables resize the whole staircase. To move a whole polyline, use x and y (see Center Point below).

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-var id="stepWidth" value="100"></pxl-var>
    <pxl-var id="stepHeight" value="100"></pxl-var>

    <!-- Left: Staircase -->
    <pxl-polyline stroke="#f97316" strokewidth="4"
      points="50,400;
              ref.stepWidth.value,0; 0,-ref.stepHeight.value;
              ref.stepWidth.value,0; 0,-ref.stepHeight.value;
              ref.stepWidth.value,0; 0,-ref.stepHeight.value;
              ref.stepWidth.value,0"
      mode="relative">
    </pxl-polyline>

    <!-- Right: House -->
    <pxl-polyline stroke="#3b82f6" strokewidth="4" fill="#dbeafe66"
      points="600,400; 200,0; 0,-150; -100,-100; -100,100"
      mode="relative" closed="true">
    </pxl-polyline>
  </pxl-layer>
</pxl-stage>

6. Arrowheads

An open polyline can carry an arrowhead at its first point (arrowstart) and at its last point (arrowend). On a smooth polyline the head follows the curve into its end, and the stroke stops inside the head, so neither pokes out of the other.

A closed polyline has no ends, so it ignores arrowheads.

More on Arrowheads

For sizing, styles, and further examples, see the dedicated Arrowheads guide.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Left: Zig-Zag -->
    <pxl-polyline stroke="#f97316" strokewidth="6"
      points="50,300; 150,200; 350,400; 450,300"
      smooth="1" arrowend="40"
      arrowstyle="filled">
    </pxl-polyline>

    <!-- Right: U-Turn -->
    <pxl-polyline stroke="#3b82f6" strokewidth="6"
      points="600,200; 800,200; 900,300; 800,400; 650,400"
      arrowstart="0" arrowend="40" smooth="1"
      arrowstyle="line">
    </pxl-polyline>
  </pxl-layer>
</pxl-stage>

7. Center Point

A polyline rotates and scales around its center point (x, y). Because its points are measured from the center point, where the center sits along the polyline decides how it turns: around its first point, its middle, or its last point.

Relative Points

The points are measured from the center point (x, y), which is also the point the polyline rotates (rotate) and scales (zoom, scalex, scaley) around. Without x and y, the center point is the layer origin (0, 0) — usually the top-left corner of the stage.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- Top: Center at First Point -->
    <pxl-polyline stroke="#f97316" strokewidth="4"
      points="0,0; 100,-50; 300,50; 400,0"
      x="300" y="150" rotate="0">
    </pxl-polyline>

    <!-- Middle: Center at Midpoint -->
    <pxl-polyline stroke="#3b82f6" strokewidth="4"
      points="-200,0; -100,-50; 100,50; 200,0"
      x="500" y="300" rotate="0">
    </pxl-polyline>

    <!-- Bottom: Center at Last Point -->
    <pxl-polyline stroke="#22c55e" strokewidth="4"
      points="-400,0; -300,-50; -100,50; 0,0"
      x="700" y="450" rotate="0">
    </pxl-polyline>
  </pxl-layer>
</pxl-stage>

8. Animated Points

Every x and every y value can animate on its own, with t, the time in seconds, or with a time driver like wave(2). Values can also follow a variable, and a variable can animate itself, so several points can share one animation.

The wave's phase variable is t * 3, and each point adds its own offset (+ 0.8, + 1.6, …): the points rise and fall one after another, so the wave travels along the polyline. Nine points, 50 apart, hold one full wave, and smooth="1" bends them into a clean curve. y="300" moves the whole wave down, so the points only hold the swing. The spring uses mode="relative": every step is the same offset ref.step.value, so animating that one variable stretches and compresses the whole spring.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <pxl-var id="phase" value="t * 3"></pxl-var>
    <pxl-var id="step" value="25 + wave(2) * 25"></pxl-var>

    <!-- Left: Wave -->
    <pxl-polyline y="300" stroke="#f97316" strokewidth="4" smooth="1"
      points="50,sin(ref.phase.value) * 60;
              100,sin(ref.phase.value + 0.8) * 60;
              150,sin(ref.phase.value + 1.6) * 60;
              200,sin(ref.phase.value + 2.4) * 60;
              250,sin(ref.phase.value + 3.2) * 60;
              300,sin(ref.phase.value + 4) * 60;
              350,sin(ref.phase.value + 4.8) * 60;
              400,sin(ref.phase.value + 5.6) * 60;
              450,sin(ref.phase.value + 6.4) * 60">
    </pxl-polyline>

    <!-- Right: Spring -->
    <pxl-polyline stroke="#3b82f6" strokewidth="4" mode="relative"
      points="750 - ref.step.value * 3.5, 300; ref.step.value,-50;
              ref.step.value,100; ref.step.value,-100; ref.step.value,100;
              ref.step.value,-100; ref.step.value,100; ref.step.value,-50">
    </pxl-polyline>
  </pxl-layer>
</pxl-stage>

9. Showcase

An op-art grid inspired by Victor Vasarely's Vega series: the lines bow outward into a breathing sphere. Each curved line is one smooth polyline whose middle point follows a shared bulge variable. To meet the edge of the stage straight, each polyline mirrors its bulge outside the stage, so the edge is a middle point with a straight tangent instead of a free end. The straight grid lines sit in a static background <pxl-layer>, which the engine caches, so only the curves are redrawn each frame.

10. Element Reference

The table below covers all attributes, runtime properties, and event handlers supported by <pxl-polyline>. Use the tabs to switch between polyline-specific features and common APIs shared across all shapes.

Polyline Path Attributes
points
'x,y; x,y; …' (each value number | expr) default: none
List of points: semicolons separate the points, a comma separates the x and y value of a point (e.g. points="50,300; 150,200; 350,400"). Every x and y value is its own expression. Points are measured from the center point (x, y). At least 2 points are needed to draw anything.
closed
false | true default: false
When true, adds the segment from the last point back to the first one, so the outline wraps around. There is no need to repeat the first point. The fill always reaches back to the first point; closed only decides whether that last edge is stroked.
smooth
false | true | number | expr default: false
Turns the straight segments into a curve that passes through every point. A bare smooth or true is the same as 1. The number sets the tension: 0 keeps the segments straight, higher values bend the curve further out. A point written twice stays a sharp corner.
mode
'absolute' | 'relative' default: 'absolute'
With 'relative', every point after the first is an offset from the point before it. Only the first point is a position.
Arrowhead Decorations
arrowstart
'auto' | number default: 0
Draws an arrowhead at the first point of an open polyline. Use 'auto' to automatically scale the size to strokewidth * 3.6. On a smooth polyline the head follows the curve into its end. Arrowheads require a stroke and are ignored on closed polylines.
arrowend
'auto' | number default: 0
Draws an arrowhead at the last point of an open polyline. Use 'auto' to automatically scale the size to strokewidth * 3.6.
arrowstyle
'filled' | 'line' default: 'filled'
Visual appearance of the arrowheads ('filled' solid triangle vs. 'line' open v-shape).
