CSS COMPOSITING VS CANVAS COMPOSITING

A side-by-side comparison of rendering states applied at the Layer level (CSS DOM) vs the Shape level (HTML5 Canvas Context).

1. Alpha (Opacity)

Layer Level (CSS)

Applying alpha="0.5" to a layer flattens the shapes first, then makes the entire canvas translucent.

Shape Level (Canvas)

Applying alpha="0.5" to overlapping shapes causes them to bleed through each other during drawing.

2. Blend Modes

Layer Level (CSS)

Applying blend="screen" to a layer blends the entire layer canvas with the background page.

BACKGROUND

Shape Level (Canvas)

Applying blend="screen" to shapes blends them against each other *inside* the layer canvas buffer.

BACKGROUND
3. Filters (Blur)

Layer Level (CSS)

Layer blur operates on the flattened image. Notice how the seam between the two shapes remains completely opaque.

Shape Level (Canvas)

Shape blur applies per-draw. Notice how the seam between the shapes becomes translucent, revealing the checkerboard background!

4. Filters (Complex & Animated)

Layer Level (CSS)

Uses Fast Path cssOnly rendering. The canvas doesn't redraw, only CSS filter property changes.

Shape Level (Canvas)

Requires full canvas clear & redraw every frame. Shapes process filter array individually.

5. Shadows (Silhouette vs Native)

Layer Level (CSS Silhouette)

Note: Layers do not support shadow* attributes! Use filter="dropShadow(0, 20, 20, '#0ff')" to trace the combined silhouette.

Shape Level (Native Canvas Shadows)

Using shadowcolor="#0ff" etc. shapes cast individual shadows, which can overlap other shapes in the layer.
