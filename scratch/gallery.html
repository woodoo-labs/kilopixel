Example 2: The Gallery

Because the Vector Mode operates in normalized coordinates, it seamlessly adapts to different shape dimensions. Try adjusting the size and rotation of the shapes below to see how the vector anchors stretch and rotate with the shape's bounding box.

<pxl-stage ratio="5 / 3">
  <pxl-layer>
    <!-- 1. Ellipse -->
    <pxl-ellipse x="150" y="300" rx="100" ry="200" rotate="0" 
      fill="linear([0, 0, 1, 1], ['darkorange', 'gold', 'crimson'])"></pxl-ellipse>
      
    <!-- 2. Hard Split Rounded Rect -->
    <pxl-rect x="500" y="300" w="300" h="200" r="20" rotate="0" 
      fill="linear([1, 0, 0, 1], [0, '#3b82f6', 0.5, '#3b82f6', 0.501, '#93c5fd', 1, '#93c5fd'])"></pxl-rect>

    <!-- 3. Gradient Text -->
    <pxl-text x="850" y="300" size="150" weight="800" font="Inter" rotate="0" text="'pxl'" align="center" baseline="middle"
      fill="linear([0, 0, 1, 1], ['#8b5cf6', '#ec4899', '#f59e0b'])"></pxl-text>
  </pxl-layer>
</pxl-stage>
