Framework Tests

Level 4 of design/2026-11-15_testing_plan.md: the DOM contract that frameworks rely on (design/2026-10-30_framework_compatibility_plan.md §2, §11), tested with plain DOM calls and no framework. Each test does what React, Vue, Svelte, Solid, Angular, Lit, Alpine or htmx do to an element: create it detached, set attributes or properties, listen to events, insert, move and remove it. Tests marked "known" are features that are not built yet (events W1, properties W3); they are the acceptance tests of the plan's steps 3 and 4. Run with node tools/run_tests.js --tests, or here via the dev server (?grep= for a subset).

Covered elsewhere, not repeated here: an id set, renamed or removed after insertion (T-C2, T-C2b), a second copy of the script, text children of shapes (C17), moves between layers, into groups and to another stage, a stage inserted again, layer.innerHTML (T-M3), the stage styles (T-S1, T-S2), mouseX across the layer's shadow root (T-E5) and its light DOM after insertion are in tests/index.html; empty and removed values of every attribute (T-C4) in tests/unit.html; the bounded expression caches (T-K1) in tests/scaling.html; the import without a window (SSR) in the build checks (tools/check_build.js).
