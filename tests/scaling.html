Scaling Tests

Level 6 of design/2026-11-15_testing_plan.md: tests that time an operation at two sizes and compare the times. Ratios are the same on every machine, unlike absolute times. Each size is measured five times and the median counts.

  • Linear work (most tests): n against 2n. Linear work takes about twice as long (ratio 2), quadratic work about four times as long; a test fails above 3.5. n grows until the smaller time is at least 5 ms (shorter times are mostly noise). Over the limit, both sizes are measured again, then 2n against 4n: a step where the elements outgrow the CPU caches makes only one pair look quadratic.
  • Work that must not depend on the scene's size (setting a property): the same work in a scene of n and of 4n elements; fails above ratio 2.
  • Bounded memory: counts cache entries instead of timing.

Slow, so node tools/run_tests.js --tests leaves this page out: run node tools/run_tests.js (or --tests --slow), or open it here via the dev server.
