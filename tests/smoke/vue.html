Kilopixel in Vue 3 (smoke page)

Vue 3.5 from jsDelivr (the build with the template compiler), no build step. The scene of checks.js in Vue's syntax: :r="r" sets properties (Vue sets a property when the element has one), @click, @click.stop, @pointerenter / @pointerleave (direct listeners), :style. The one setting Vue needs: compilerOptions.isCustomElement for pxl-*. The checks run when the page loads (?grep=skip skips them, to try the scene with the mouse).
