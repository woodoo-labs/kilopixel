Engine Tests

Run after every engine change (after node build.js): node tools/run_tests.js --tests runs this page and the other test pages headless. In the browser, via the dev server: http://localhost:8124/tests/, or ?grep=toLocal for the tests whose name or section contains a text. The result is also shown in the tab title (Tests: N/N passed) and stored in window.kilopixelTests. Add a test for every engine fix, and a test.known() for a bug found but not fixed.
